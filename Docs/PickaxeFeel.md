# 矿镐换模与初始墙挖掘

矿镐的五级模型在玩家创建时加载并保持引用，同时用隐藏组件预热材质管线和贴图。购买升级只切换已驻留的模型，不再在购买回调里同步读资源。升级后播放 0.65 秒抬起、轻转、归位动作；新的挖掘输入可以立即打断动作。重复应用同一级升级不会重复播放动画。盲人通路内换模会清理旧的描边材质覆盖，再应用当前通路样式。

挖掘仍优先使用落镐时准星实际命中的岩层。若挥镐时已经命中土层，但落镐前准星只发生小幅漂移，可重新检查原落点：偏移不超过 8 cm（且不超过挖掘半径的 10%）、角度不超过 4 度、仍在原挖掘距离内，并且当前相机到原落点之间没有其他遮挡时，完成原来的这一击。明显转开、打开阻断输入的菜单、切换工具、离开距离或原地形已被移除时，不会继续挖旧位置。

验证入口：`Scripts/Run_PickaxeFeelChecks.ps1 -Native` 与 `Scripts/Run_PickaxeFeelChecks.ps1 -Render`。后者加载正式 MainGame，在 PIE 中取得初始矿镐，测试首面土墙九处位置的连续短按、边缘轻微漂移与主动转开，再实际购买四级升级并检查立即换模、动作、归位和截图。测试不保存关卡，使用独立 UserDir。报告位于 `Saved/Validation/PickaxeFeel`。

2026-10-18：编译通过，16 项原生测试和 32 项正式 MainGame 运行检查通过。四次升级购买回调分别约 0.36、0.16、0.24、0.16 ms；这是本机本轮购买回调耗时，不代表整个渲染帧耗时。四级模型均在购买调用返回时已赋值，动画期间保持可见，结束后归位。初始墙九处位置各连续短按四次，命中泥土时均成功开凿，挖通后的空处不再重复切割；额外的轻微偏移和主动转开两种输入也符合预期。
