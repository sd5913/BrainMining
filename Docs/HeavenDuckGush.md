# 天堂马桶定向喷鸭

实现位于 `Source/BrainMining/HeavenToilet.h/.cpp`，应用于实际关卡中的 `AHeavenToilet`，无需重存关卡。收藏册仍使用原来的静态展示逻辑。

## 行为与参数

| 状态 | 默认行为 |
| --- | --- |
| 远处 / 刚进入房间 | 保留原有每 3.2 秒一轮、每轮随机 5–7 只、向周围散射 |
| 靠近本体 | 水平距离小于 700 cm，触发密集定向喷涌 |
| 喷涌 | 每秒 28 只，连续 10 秒；方向缓慢跟随玩家，转向速度上限 18°/s，接近目标方向时平滑减速 |
| 暂停 | 2.5 秒不喷鸭，然后按玩家新位置启动下一轮 |
| 离开 | 超过 850 cm 恢复普通节奏；进入 / 离开距离差避免边界抖动 |
| 负载 | 固定 160 个网格组件复用；接近上限时优先将最老的落地鸭子在 0.35 秒内缩小回收 |

密集喷涌使用 560 cm/s 上抛速度、左右各约 9° 的扩散，根据玩家距离平滑调整水平速度，形成集中抛物线。每轮开始时朝向玩家，随后以指数平滑和角速度上限慢慢追随；跨越 ±180° 时走最短转向。只有新喷出的鸭子使用更新后的方向，已在空中的鸭子保持抛物线飞行。保留原鸭子模型、尺寸、水面、场景和持续喷水。

不创建鸭子 Actor 或刚体模拟。只有空中的鸭子执行碰撞 sweep；落地后停止运动与碰撞查询。回收过程中维持网格底部贴地。正常负载预留 20 个槽位；极端自定义参数占满池时也不会复用空中鸭子。落地 22 秒后自然回收，意外飞出地面的鸭子最多保留 12 秒。

`Toilet|DuckGush` 分类可调整距离、喷涌 / 暂停时间、跟随转向速度、密度、上抛速度和池容量（64–256）。容量在 BeginPlay 时分配；修改容量需重新运行。

## 验证与录像

先编译 `BrainMiningEditor Win64 Development`，再执行：

```powershell
& Scripts/Record_HeavenDuckGush.ps1
python Scripts/encode_heaven_duck_review.py
```

录像运行正式 `Lvl_MainGame` 关卡中的实际玩家与马桶逻辑；仅测试机位、玩家摆位及区域进入使用 PIE 辅助接口，不修改或保存关卡。启动器强制 `-NoSteam` 和独立 `-UserDir`。

`Saved/Review/HeavenDuckGush/latest-take.txt` 指向本次输出目录，包含逐帧 JPG、真实时间戳、运行状态、自动检查结果、现场音频及带中文说明的 MP4。编码器按真实时间戳合成，不加速喷涌。

检查覆盖普通喷鸭密度、空中密度、数量上限、负载回收、两轮完整 10 秒喷涌、2.5 秒暂停、转向速度上限、移动中的跟随延迟、玩家停下后瞄准收敛、暂停无出鸭、离开后恢复及持续水特效。录像读回 GPU 会增加开销，录像帧率不能作为独立性能基准。
