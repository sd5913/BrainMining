# 挖哦！移动端 UI · 岩切 / 方向 01

2026-10-20。此目录保留可编辑 SVG 与网页预览；纯图标方案现已接入游戏移动端。运行时图标位于 `Content/UI/Mobile/`，由 Slate 加载，随 APK 的 NonUFS 内容打包。

第二版按用户要求改为纯图标：移除所有可见标题、口号、按钮名称、解释及底部注释；只保留矿石数量、能量百分比、炸弹余量和升级数值。预览导航、暂停及设置也使用图标。控件的无障碍名称仍保留，供键盘和读屏使用，不会显示在画面上。

打开 `preview.html` 查看四个页面，点击暂停、升级以及暂停页的设置。探索页支持按住挖矿、钻机或喷气并拖动场景，演示同指操作；这不是 Unreal 的输入验证。

## 视觉方向

取自现有 Android 游戏截图的矿灯暖黄、奶白、岩灰与工具灰绿。轮廓参考矿石切面及原有道具切角底板，以平面色块和统一工具图标取代英文白圆按钮。中央保留场景，左下仅保留移动摇杆。背景是独立绘制的矢量矿洞示意，非新版游戏实机画面。

## 页面

- `hud.svg`：横屏探索；四种矿物数量、升级、暂停、移动、交互、钻机、喷气、炸弹、挖矿。
- `pause.svg`：暂停后的继续、声音与震动、操作设置、图标页、退出游戏。离开流程需二次确认。
- `upgrade.svg`：升级面板视觉提案；等级、材料和费用是排版样例，正式实现使用实际进度系统。
- `contexts.svg`：从左上到右下依次为电脑、盲人、思维、卡牌与收集的动作图标；下方从左到右为待机、按下、不可用状态。画面没有文字图例。
- `icons/*.svg`：20 个独立矢量图标，64 × 64 viewBox。

SVG 数值保持可编辑。运行时数值使用项目现有字体，不显示按钮名称、标题或操作解释。

## 运行时触控

1600 × 720 参考画布中，主挖矿键视觉半径 76、命中半径 84，辅助键视觉半径 52、命中半径 58。按屏幕等比缩放，使用安全区布局。布局自动检查覆盖 1280 × 720、1600 × 720、2400 × 1080、800 × 360；最终手感仍需手机试按。

- 工具按下立即反馈；挖矿、钻机、喷气指针捕获后，同指位移持续传给视角。
- 点按与长按共享同一次起始动作，避免为了判断长按而延后首击。
- 交互不因当前无目标而消失；未解锁或耗尽的工具降低饱和度，能量与余量使用数值显示。
- 特殊房间隐藏无关挖掘工具；电脑/卡牌模态界面禁止穿透到挖矿或相机。
- 暂停和失焦必须释放所有持续动作，恢复时不补触发炸弹或购买。
- 暂停菜单与情境返回分别处理；返回电脑不能误触暂停，关闭暂停后恢复原情境。
- 升级后显示成功、材料不足、已满级等反馈；不能仅变色却没有原因。

使用 `python generate.py --game-assets` 同步生成 SVG、预览和游戏图标。此目录 PNG 是设计预览；游戏截图输出至 `Saved/Validation/MobileUI/`。

## 验证

- `Scripts/verify_gamepad.ps1 -TestFilter 'BrainMining.Mobile+BrainMining.Android.CompatibilityProfiles+BrainMining.Gamepad.DeadZone+BrainMining.Gamepad.ContextAndRelease'`：编译并检查布局、图标文件、同指拖动、多指输入、暂停/房间模态/失焦释放及恢复；同时回归 Android 兼容配置与手柄输入。
- 桌面游戏加 `-MobileUI` 可强制显示触控界面。开发构建中的 `bm.Mobile.Capture` 捕获主关卡 HUD、暂停和升级面板后退出，不进入 Shipping。
- 单任务编译，限制编译并发为 1；截图和打包顺序运行，使用 `Scripts/ResourceGuard.ps1` 监测内存余量。
- 内存紧张时，打包脚本可选择 `Start-MiningGuardedProcess -TrimCookWorkingSet`：仅回收本次启动的 Cook 子进程可分页工作集，保持原有内存停止阈值；应优先复用上一版成功构建使用的缓存目录。
