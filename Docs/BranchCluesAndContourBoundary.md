# 藏品线索、博物馆与通路边界（2026-10-25）

本轮更新包含七件新增场景藏品的独立位置与土层线索，以及普通玩法钻机和博物馆持握显示调整。

- 七件场景藏品与矿石主体、矿石表面及碎晶保持至少 5 米距离。太极改至第三段后部路边，避开天堂马桶分支。位置记录在 `Config/BranchCollectiblePlacements.json`，不会改变藏品 ID 或矿石生成记录。
- 水世界线索使用有铰合端、扇形边缘及放射棱纹的贝壳；太极线索为中心留空的八卦卦爻；地铁为深色底向上箭头及「乘车 / To Train」。烤肉香气使用连续、柔边、随时间变化的蒸汽材质和贴合土面的气孔。
- 钱袋线索为散落钱币，手机线索为评论框，鸡尾酒线索为柑橘切片与酒渍。线索随支撑土层被挖掉而移除。
- 博物馆内隐藏手持镐、炸弹、钻机，切换工具不能使它们重新出现。镜中矿工移除矿镐，改戴简洁的淡黄色照灯帽。
- 普通钻机单独调整前后位置、左右间距和大小，让开放的模型后端位于画面之外；检查默认 100° 和最大 115° 视野下的待机、旋转及切换。结局只作为外观参考，镜头和钻机实现不变。实际能量恢复为配置速率的 60%，默认每秒 10 → 6；同时适用于待机和收起状态，不改总能量。
- 通路外壳基于当前配置的通路切割模型向外约 20 米生成；保留房间接口和原始内部地形，在原箱体外补充可挖土层。天堂房及玩法房间采用原有专门边界，避免修改房间内部。三段外壳各约 4 万三角面，均为闭合网格；抽样内外表面距当前通路约 19.78–22.30 米（含约 2 米壁厚）。仅新通路外壳启用双面碰撞，防止从凹面穿出；原始可挖土层和对象 ID 保留。
