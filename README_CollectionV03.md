# 挖掘收集 V0.3：同事演示版

双击工程根目录 `Play_Collection_V03.cmd`。独立地图为 `/Game/CollectionPrototype/Maps/Lvl_Collection_V03`。

- 距离参数由 1100 cm 缩为 750 cm，缩短约 32%。试管距入口约 7.5 米；洞穴入口约 7.2 米，洞内藏品约 10.4 米。保留沿线索逐步深入的过程。
- 化学污渍直接着色在实际土体网格上，采用不规则的绿紫残留和流痕。挖掉对应土面时，该处污渍随网格消失；新的土面可露出更深层残留。不再生成七彩圆块，不存在独立悬空的污渍物体。
- 羽毛有明确的羽片、缺口和浅色羽轴。入口三片、土层中四片。未挖掉支撑时保持附着；支撑消失后摇摆飘落，碰到实际地面或坡面后停下，约 12 秒后清理。继续挖掉落点支撑时可再次下落。
- 外侧鸟窝的木片失去土层支撑时清除，避免挖空后悬浮。洞内鸟巢和原有鸟群出洞演出保留。
- V0.1、V0.2 地图与原挖掘 Demo 保留，默认启动地图不变。新线索逻辑也供 V0.2 使用，但其 1100 cm 距离配置保留。

操作：WASD 移动，鼠标观察，按住左键挖掘，E 收集，按住空格飞行，Tab 打开图鉴。图鉴内拖动旋转、滚轮缩放，F 复位。R 开始新一轮，Alt+F4 关闭试玩。

建议演示：观察化学污渍并挖掉一块土面 → 飞到鸟窝，挖掉羽毛下方的土 → 沿管道快速找到马桶 → 收集后打开图鉴。

停止 Play 后可选中 `V03 demonstration collection rules` 调整 `Excavation Depth`，V0.3 默认 750 cm。输入正数 `Random Seed` 可固定演示布局，0 保持每轮随机。

验证脚本：`Scripts/verify_collection_v3.py`；报告：`Saved/Validation/collection_v03_runtime.json`。画面检查脚本：`Scripts/capture_collection_v3.py`。验证在独立进程运行，不保存对关卡的测试切割。

本次编译和 52 项运行期检查通过，覆盖羽毛受支撑时静止、局部切割后飘落、相邻羽毛保留、实际地面落地、重置、四类收集、鸟群演出及原挖掘 Demo。测试路线分别使用 6–7 次有效切割完成收集；测试会自动摆放角色，实际演示时长以人工试玩为准。旧地图、配置和已有项目改动共 17 个基线文件哈希未变化。

边界：羽毛使用程序化飘落和碰撞检测，不是布料模拟；每局收集仍不做跨局存档。
