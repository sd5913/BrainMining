# 退出确认与平行菜单按钮（2026-10-23）

Windows Esc 暂停菜单移除退出游戏，仅保留继续游戏、查看藏品、设置、保存进度、返回主界面。谢幕后的 Esc 同样进入该暂停菜单，不直接弹出退出确认。

主界面点击退出游戏先弹出“确定退出游戏？”，提供“取消 / 确认退出”，默认焦点为取消。Esc 或默认回车会取消并恢复主界面焦点、鼠标状态；只有确认退出才终止程序。弹窗与取消不会写入存档，也不会解除初始镜头的控制锁。保留现有移动端暂停确认行为。

三个按钮统一采用开始游戏的 +7° 角度和 +10° 斜切，文字从左上向右下倾斜并彼此平行；继续、开始、退出的水平偏移仍为 +18 / +4 / -12，保留从上到下向左错落及整体避开椅背的位置。

最终 Windows Shipping 包通过 `verify_packaged31.py` 的 15 项真实 Slate 指针/键盘检查：倾角和平行、排列方向、点击退出不会立即关闭、取消/ Esc /默认回车、反复取消后继续游戏的输入恢复、暂停菜单动作、返回主界面、真正确认退出及存档哈希不变。另外 `verify_packaged28.py` 的 37 项悬停、按住、移出取消和继续读档检查通过。已目视检查主界面、二次确认和无退出项的暂停界面。

使用独立 QA 存档副本，未修改玩家存档。初次验证在载入的旧测试检查点尚未满足保存条件时就点击返回，触发现有保存保护；最终测试等待保存就绪后，再验证真实返回按钮，全部通过。Editor、Shipping 编译及打包资源审计通过。
