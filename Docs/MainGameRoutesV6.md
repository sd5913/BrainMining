## 可复现管线

1. Blender 后台运行 `build_main_game_routes_v6.py`，生成加高洞厅、平台及路线数据；`validate_routes_v6_blender.py` 检查净空和平台。
2. `apply_main_game_routes_v6.py` 首次运行导出所有原始闭合体到 `Art/MainGame/RoutesV6/LayerOwnership`，未生成分层结果时停止且不保存地图。
3. Python 3.11 安装 `manifold3d==3.5.4`、`numpy==2.4.6` 到 `Saved/Tools/geometry`，执行 `build_routes_v6_layer_ownership.py`。双精度布尔运算同时生成闭合体和 18 米网格分块，验证各分块体积之和。编辑器导入时检查源文件哈希与各块拓扑。
4. 再执行安装脚本，更新 MainGame 与三份配置；脚本有版本标记以阻止重复变形，并记录备份。随后执行 `update_routes_v6_wall_material.py` 更新第二矿区的泥土色过渡位置。

通过 `run_routes_v5.ps1 -Script <脚本名>` 顺序执行 Unreal 脚本；需要画面时加 `-Render`。验证入口为 `verify_routes_v6_ownership.py`、`verify_main_game_routes_v6.py`、`verify_routes_v6_presentation.py`、`verify_routes_v6_blast_seams.py`。实际结果以 `Saved/Validation/MainGameRoutesV6` 下的报告为准。
