# 矿镐养成数值工具

入口：UE 编辑器顶部 **工具 → 矿镐养成数值**。需要先编译包含本工具的 BrainMiningEditor。

## 调整与保存

1. 展开“矿镐等级”下的等级数组。0 是初始矿镐，1～4 是四次购买升级，破坏等级自动对应 0～4。
2. 在等级 0 填写每击基础深度（厘米）、范围边长（厘米）及挥镐间隔（秒）。其他等级自动继承；2 级起范围累计 ×1.25，3 级起间隔累计 ×0.75，可在“升级倍率”修改这两个倍率。边长不等于面积或半径。实际宽深仍乘人物挖掘尺寸倍率，例如 0.7 倍体型时，320 cm 基础边长实际为 224 cm。
3. 每击深度按“破坏等级减命中岩层硬度”修正，差值 ≤-4 时无法破坏；硬度不会改变洞口边长或挥镐间隔。对应倍率、场景硬度和配置文件字段见 [PickaxeHardness.md](PickaxeHardness.md)。
4. 下方“目标等级”用于试玩草稿。旧三击/两击快捷按钮已移除，当前养成每击独立计算，不固定任意厚度墙体的总击数。
5. 轮廓随机强度、价格和商店说明仍可逐级设置。说明留空时自动显示破坏等级、范围、每击基础深度与间隔；商店读取同一配置。
6. 检查顶部校验提示和五档概览，点击“保存并应用”。无效草稿不会保存或应用。保存只更新 Config/DefaultGame.ini 中的 MiningPickaxeSettings 配置节，可随 Git 提交，重启和打包后仍生效。

“推荐预设”和“重新读取已保存配置”都只替换当前草稿，可 Ctrl+Z 撤销。后者读取当前编辑器已保存的配置；在外部手改 ini 后需重启编辑器。关闭窗口会丢弃未保存草稿，工具不自动保存地图或蓝图。

## 试玩

在“矿物提示 → 矿物发光范围倍率”调整埋藏矿物的穿透光晕，范围为 0.25～4，默认 2（此前固定为 4）。最终半径是每种矿物的提示半径乘以此数值。点击“在当前试玩中试用草稿”可即时预览，点击“恢复已购等级”恢复已保存的光晕设置；“保存并应用”会同时更新当前试玩并写入配置，后续生成的矿物也使用该设置。

在编辑器内开始试玩，角色出现后按 Shift+F1 释放鼠标。选择目标等级并点击“在当前试玩中试用草稿”，无需购买即可试用该档数值。此操作不保存、不扣金币、不修改已购等级。适用于编辑器内 PIE，包括当前所有 PIE 世界中的采矿组件；独立游戏进程需保存后重新启动。

如果 Shift+F1 被 Snipaste 等软件的全局快捷键占用，可使用窗口化 PIE，再通过 Alt+Tab 切回“矿镐养成数值”窗口操作。

“恢复已购等级”恢复已保存配置及玩家实际购买等级；“保存并应用”同样按已购等级应用，而不是把目标等级设为购买等级。游戏中购买升级也会覆盖临时试用属性。

当前硬度模式每击独立使用命中位置的硬度及当前已购等级，升级会影响后续挥镐。只有显式使用旧阶段 API 的流程才沿用既有凹坑的阶段快照。

## 推荐初值

- 基础：范围边长 320 cm、每击深度 208 cm、间隔 0.3 秒。
- 破坏等级：初始 0，购买四次后依次为 1、2、3、4。
- 2 级起累计范围边长 400 cm；3 级起累计间隔 0.225 秒。
- 四次升级价格维持 50、1000、5000、50000 金币。

随机强度默认 1，保留原有完整随机幅度；0 关闭轮廓随机，但仍保留凹坑的收口切面。尺寸是标称切割体参数，实际洞口会受收口、岩壁方向及随机起伏影响。较大的尺寸会涉及更多地形块，需在正式矿区观察流畅度。

## 与旧配置的关系

- 正式矿镐以该工具的全局配置为准，蓝图中旧的矿镐升级步骤不再覆盖价格、描述和成长属性。
- 矿镐宽深和间隔独立于钻机。旧 Radius、DepthMultiplier、Interval 继续作为钻机基础参数；没有进入游戏、也没有应用新配置的底层组件保留旧路径，以兼容旧几何测试。
- 射程、下移量等操作参数仍使用原组件设置。本工具只调养成数值。
- 第四次升级仅提升破坏等级；沿用 2、3 级取得的范围和间隔增益，不再提供旧的两击设定或收矿双倍金币概率。其他装备升级不变。
- 非法的外部配置会使运行时回退整套推荐曲线；面板会显示具体错误，修复并保存后生效。
