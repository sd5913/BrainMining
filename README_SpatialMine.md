# 三维隧道编辑器

## 当前默认：自由草稿与自动外围（2026-10-09）

三维矿区现在默认开启 **自动包裹可挖岩体** 和 **自由编辑**。旧二维工具不变；关闭这两个选项可回到三维工具原来的固定矿区/受限编辑方式。下文较早的“每一步合法”“超出岩石范围”“入口必须放进墙面”等说明仅适用于旧模式。

1. 在面板选择通道、房间或矿区，找到 **自动岩体与基岩（厘米）**。
2. **可挖余量**控制初始空间外还留多少可挖岩石，默认400cm；**基岩厚度**默认100cm。无需扩大或移动手动矿区盒子。
3. 外围按路径的局部分段、主房间、支线房间及空洞合并生成，不是简单放大整张地图的总包围盒。它是分段凸包外扩，转角附近可能留出更多可挖空间，不是精确等距光滑曲面。
4. 关闭 **空间灰模预览** 查看真正生成的岩体与基岩。总包围框只是参考范围，不是实际基岩形状。运行时基岩固定，不会随玩家挖掘无限外移。
5. 自由模式中，未完成或暂时自交的轮廓可以继续编辑、保存，不会被弹回。只有“地形已应用”才代表当前设计已生成；开玩仍会拒绝未生成的草稿，避免静默玩到旧地图。
6. 首次打开已有地图，点击面板上方 **检查并重建** 应用自动外围，再确认状态并保存。打开工具本身不会替你保存地图。

自动模式不再因为固定岩石盒子、入口截面大于墙面、其他入口不在指定主墙、矿区包围盒相交或局部超过旧转向角阈值而直接拒绝。入口位置仍可绑定房间墙面，但方向不再强制沿法线；需要旧行为时勾选入口的 **入口方向对齐墙面**。通道自身的三维交汇会尝试实体自合并；无法得到封闭实体时保留草稿并说明原因，不承诺任何退化/自交轮廓都能生成。

同一生成器下所有矿区均开启自动外围时，跨矿区交汇会清除相互填回的岩石，并划分岩体归属，避免同一位置出现两层可挖岩石；与旧固定矿区混用时仍保留旧布局检查。仍可相互进入的矿区不使用旧单入口封口回收，避免误删玩家可进入的空间；面板/生成器会给出提示。这类布局可能保留更多历史岩体，不保证与纯线性回收地图相同的总内存占用。

运行时预算不提高：每块最多30,000三角形、每矿区最多128格。路径2–64节点、最多256个采样截面和64个统一轮廓采样点等生成预算仍保留；未启用的空间不再占64个启用空间名额。主房间旋转、无效数值、退化轮廓及唯一生成器归属等必要限制仍在。超预算时请减小可挖余量或拆分设计，不会偷偷提高预算或改变造型。

回归入口：`Automation RunTests BrainMining.Spatial.Freedom`。现有严格模式测试显式关闭新选项，继续验证旧地图行为。

本次独立副本验证：全部53项自动化测试通过；已保存的三维示例地图保留全部设计输入，生成72块岩体、最大1540三角形/块。另验证了无效草稿保存后重开、继续修改恢复，以及挖掘可挖余量时外围基岩不变。验证脚本为 `Scripts/verify_spatial_freedom.py`，仅允许在 `Saved/Validation` 中的独立项目运行，不修改原地图。

这套工具是独立新增的三维版本，不转换或覆盖 `Lvl_MiningManual_Demo`。旧的二维钢笔工具继续保留。

## 打开

1. 打开 `/Game/MiningPrototype/Maps/Lvl_MiningSpatial_Demo`。
2. 菜单 **工具 → 三维隧道编辑器**。也可在 Unreal 的 Python 控制台执行 `unreal.MiningDesignerLibrary.open_spatial_editor()`。
3. 从场景大纲或工具的“选择空间 / 矿区”菜单选择三维主通道。
4. 默认使用“空间灰模预览”，直接看空间体积；岩石仅在当前编辑视口中被遮蔽，不修改 Actor 可见性。关闭预览或关闭工具即显示原场景，不改游戏碰撞或生成器预览属性。灰模有独立明暗，不受矿井的黑暗灯光和自动曝光干扰。

## 直接搭建（默认）

日常操作在主视口完成，数值、切线和旧草稿修复收进“高级编辑”。打开工具、切换工具或查看预览都不会重写已有节点与轮廓。

1. **拉通道走向**：选通道后直接拖白色节点。绿色 `+` 点按下即可插点并继续拖动，一次撤销恢复整次操作。默认沿当前屏幕平面移动；选点后也能用 W 操作轴精确限定 XYZ。
2. **勾画边界**：先点要修改的节点，再点“正对截面”。白点逐点修改轮廓，绿色 `+` 插入轮廓点；四个青色边界柄只拉该侧，对侧边界保持不动。点始终位于该节点的真实三维截面内，不限世界 XY/XZ 平面。
3. **房间**：选中主房间或支线房间，直接拖六个面的青色柄，另一面不动。顶部拉高不会把主房间地板一起抬起。先点“移动空间”再用 W 移动整体，旋转支线房间用 E；若已选中面控制点，操作轴只调整该面。尺寸保持独立参数，不缩放 Actor。
4. **空洞与支线**：在现有通道选一个节点，点击“+可编辑空洞”或“+支线房间”。新对象放在该处并切到“移动空间”，先摆位置；空洞再用“勾画边界”塑形，支线房间摆好后点击“选中房间连接主通道”。
5. **保存**：底部“保存当前关卡”或 Ctrl+S。状态区分别显示合法性、实际地形应用状态和保存结果；灰模可见不等于已经应用。

- “拖路径时自动拉顺邻近弯道”只在实际拖路径时处理该点附近的未锁定切线，不改宽度、轮廓、其他房间；关闭即可保留原切线。仅开启开关不会改已有设计。
- 房间入口点可沿所属墙面滑动，不再无反馈地拖不动；不能沿法线把入口拉离房间，前后位置应通过移动房间或房间面调整。
- 普通编辑仍经过源形状、入口、岩石边界及实际地形预算检查。拖动中的目标在后台检查，连续输入合并为最新目标；只有通过检查的结果才同步到控制点、实体地形与碰撞。受限时显示原因和目标位置提示，保持最后合法地形，不默默缩窄通道或提高预算。
- 单次直接拖动是一条撤销记录；直接拖动中 Escape 取消。Delete 删除选中的路径/轮廓控制点，不会误删整个空间；绑定入口、锁定点和必要点不能删除。
- 仅选中的空间显示控制柄。空间名称、矿区外框默认隐藏，需要时在“场景总览与视角”展开。灰模是编辑器专用源空间，不是已挖表面的实时渲染，也不写入关卡辅助 Actor。
- 紧弯、大截面和自身穿插仍受扫掠几何限制。本版没有把内核替换成任意体积雕刻器；局部洞穴/交汇仍用独立空洞或支线表达，不能强行拖出自交表面。

## 场景总览

打开工具后，会在**关卡三维视口**自动显示并聚焦当前地图的空间灰模。不必选中某条隧道：主房间、主通道、支线、支线房间、独立空洞、隐藏空洞和可挖堵块同时可见。高级编辑内的局部 UV 画布只用于编辑当前截面，不是总览窗口。关闭灰模可以恢复原线框总览。

- **全局轮廓**：启用/关闭总览；关闭后保留原有选中对象的组件编辑器。关闭工具面板也会关闭全局绘制层。
- **总览全图**：适配当前已加载且可见关卡里的全部三维设计对象和主房间，包括尚未分配矿区或未启用的草稿。不把天空、灯光、生成岩块等算入取景范围。
- **聚焦当前矿区**：适配当前矿区内的空间及起止主房间。选择隧道或支线房间会切到它所属的矿区；选择主房间会优先沿用与之相连的当前矿区。共享主房间连接多个矿区时，可从空间菜单明确选择目标矿区。
- **聚焦选中空间**：适配实际扫掠轮廓或旋转后的房间，不使用空的根组件边界。选中矿区时适配该矿区内容；没有选中对象时只提示，不乱跳镜头。
- **透视 / 顶视 XY / 正视 XZ / 侧视 YZ**：只改变当前关卡视口，沿用上一次成功的聚焦范围。正交取景按屏幕方向的实际投影宽高适配，不会因为垂直于屏幕方向的隧道很长而把画面缩成一小团。先点“总览全图”再切视角即可查看整张地图。
- **空间名称**：显示带引线的名称，自动错开重叠文字；过长名称缩略，过密时省略无法排下的标签。完整名称仍可在大纲/选择菜单查看。关闭名称可得到更干净的轮廓图。
- **矿区岩石框**：额外显示岩石范围，并在全图/矿区聚焦中计入它。默认关闭，以免大范围外框把内部通道缩得过小。
- 点击空间灰模或轮廓即可选中它。只有选中的空间显示当前工具需要的控制点，其余保持简单预览。
- 配色：青色主通道、碧绿支线、蓝色主房间、绿色支线房间、紫色空洞、橙色堵块、灰色未启用空间。选中对象沿用原有高亮/控制点样式。

轮廓在前景绘制，不会被岩石遮住；显式在大纲中隐藏的 Actor 或隐藏关卡仍不显示。移动房间、编辑 XYZ 路径/截面/扭转、改变采样误差、撤销/重做后会更新轮廓；只重新采样变更对象，不重建游戏碰撞。删除对象和切换地图会清理旧缓存。

**总览是源设计，不是“生成成功”的证明。** 无法采样的草稿显示红色中心线或小框，仍可选中继续修；自穿、越界、入口不匹配等最终建模检查仍以下方矿区状态为准。出现 `NOT APPLIED` 时实体仍为上一次有效结果。总览不增加矿道预算、不生成可保存的辅助 Actor、不在 PIE/游戏中显示；原有 30,000 三角形/块和 128 块/矿区不变。

## 高级路径与切线

以下操作位于“高级编辑”，需要勾选“显示原切线操作柄（高级模式）”。切回顶部的任意直接工具即退出高级操作柄模式。

- 在三维视口点击白色节点，按 **W** 沿 XYZ 移动；不是把 XZ 图沿 Y 挤出。
- 选中节点后出现黄色进入/离开手柄，点击手柄后拖动变换轴即可拉弯路径。
- “插入节点”或视口 **Insert** 用 De Casteljau 拆分曲线，保持中心线形状。插入位置在当前节点之后的段中点。
- “删除节点”或视口 **Delete** 删除当前节点。至少保留两个节点，绑定房间的端点不能直接删。
- 锁定的节点不能被视口拖动；切换节点不会改写其他节点的数据。
- 隧道 Actor 可以移动、旋转；Actor 缩放保持 1，尺寸用截面倍率编辑。

## 高级截面与扭转

- 每个路径节点都有自己的闭合截面轮廓，沿路径在相邻截面之间过渡。
- 点击节点后，下方画布显示该节点的**局部 UV 截面**，它不是整个世界的俯视图。
- 拖控制点改变轮廓；平滑点/独立手柄可以拉曲线；**Ctrl+点击曲线**插点；Delete 删轮廓点；支持锁定点。
- 右键拖动画布、滚轮缩放，“适配截面”重新居中。
- 顶部的“扭转°”支持累计角度，例如 0 → 360 → 720，不会把两圈自动变成零圈。
- “宽× / 高×”只改当前截面倍率，轮廓控制点仍保留。
- 视口 **E** 绕截面法线旋转，**R** 调整截面宽高；使用局部坐标系。数值输入也可以精确控制。
- 运输坐标架随路径转向，避免竖直段或反弯处使用固定世界朝向造成翻转。角色重力仍沿原来的世界方向，工具本身不增加贴墙、倒挂或任意重力移动。
- 插点精确保留中心线；截面轮廓不同的两节点之间插点后，过渡外形可能变化，需要检查预览。

## 房间、空洞、支线与岩石

- **支线房间**：中心锚点；直接移动/旋转 Actor，拖六个面的控制柄改变尺寸；高级参数仍保留。不会触发主线房间推进和回收。
- **空洞**：独立的短三维扫掠体；同样能编辑节点、截面和扭转，不限于圆球或长方体。可不连通，作为隐藏空洞。
- **支线通道**：新建通道，将入口房间指向主房间或同矿区的支线房间；另一端可保持不绑定并放入已有通道内部。
- 选中支线房间后，可以按“主通道连接选中房间”创建一条初始直连曲线，再继续拖点编辑；不自动绕行。新建或连接无法通过完整地形检查时，会拒绝这次操作，不留下半成品对象。
- 入口支持 ±X、±Y、±Z 六面；支线房间旋转后，墙面使用房间自身坐标。
- 绑定端点的位置随房间与墙面偏移变化，端点手柄方向随墙面法线，仍可修改长度；不自动重写中间节点。
- 入口的实际旋转截面必须容纳在墙面内，超出时给出错误，不偷偷缩小截面。
- **可挖堵块**：闭合的三维扫掠体，把该区域保留为普通岩石；可用于堵路或划分需要挖掘的段落。
- 不同空洞/通道相交时合并为空间。外层基岩仍在矿区边界；可挖岩石仍使用现有空间分块与挖掘系统。

## 矿区设置与安全

- 三维矿区继承原矿区数据：设置 FromRoom、ToRoom、岩石范围尺寸，并把新通道指定为“三维主通道”。生成器的 Hollow Regions 引用三维矿区。
- 不要把旧的二维 MainPassage、旧圆管 Plugs 或旧 HollowChamber 混入三维矿区；它们继续在旧矿区使用。
- 三维工具默认启用受限编辑：从合法布局开始，移动节点、手柄、截面、房间和矿区边界会同步检查并生成。不是等松手后才验证，也不会留下非法控制点配旧地形。Ctrl+Z / Ctrl+Y 和工具按钮使用编辑器事务。
- 连续调整越界时沿本次移动方向寻找安全位置；找不到合法位置则恢复原值。离散操作无法通过时整次拒绝。不自动缩小通道、不移动其他房间、不放宽原有预算。完整生成失败时保留原实体、碰撞和小地图，同时还原源数据。
- 过紧内弯、截面自交、扭转挤穿、超出矿区、无效入口会被拒绝。不同分支请用不同隧道对象连接，不要把一条扫掠体打结自穿。
- 预算不提高：**30,000 三角形/块，128 块/矿区**。单条源隧道 2–64 节点，最多 256 个采样环，截面对应轮廓最多 64 个采样点；过长或过密的形状拆成多个对象/矿区。
- 游戏中的开发者小地图默认显示三维房间和扭转通道，Tab 展开，按住 Alt 移动鼠标旋转，Alt + Shift 平移，Alt + 滚轮缩放，Backspace 恢复默认总览；V 在三维和三个平面视图间循环。小地图用真实闭合三维表面判定玩家位置，不会用整个弯道的凸包填满中间空白，也不是实时挖掘表面扫描。右侧编辑器中的二维方框仍是截面编辑区，不是这个游戏小地图。
- PIE 中禁用编辑。正式发布前需重新 Cook/打包，新编译的编辑器并不更新旧安装包。

## 看懂受限与保存反馈

1. **合法**：控制点、地形和碰撞已同步更新，可以继续拖动。向极端方向拖不动时，可立即往回拖，不需要手动修复非法草稿。
2. **已限制**：只接受安全范围内的移动；黄色提示说明过急转弯、截面挤穿、房间入口太小、矿区越界或预算不足。点击 **定位限制 / 问题**，视口会选中对应对象并聚焦黄色范围框。
3. **保存当前关卡**：先完整检查并同步地形/碰撞，再保存当前关卡；原生 Ctrl+S 保存也走相同检查。合法设计和生成结果一起保存。检查失败仍允许保存设计，但会明确显示 **仅草稿保存成功 · 地形未生效** 和原因，不再把磁盘保存成功等同于新地形可玩。自动备份不触发重建，也不会冒充手动保存成功；无新修改时再次保存仍会提示草稿状态。
4. **已有草稿尚未应用**：旧版本留下的非法形状不会被打开工具这一动作覆盖。先定位问题；对于局部急弯，可按 **平滑问题弯道**，尝试只改变问题段和相邻弯道的未锁定手柄。节点位置、截面轮廓/倍率、扭转和房间保持原样。只有完整检查通过才应用，可撤销；失败则保留原设计并明确提示。并非所有旧草稿都能只靠平滑修复。
5. **等待同步地形**：重新打开关卡后，已有生成缓存可能需要重新校验。这不等于形状非法，也不等于预算超限；编辑、保存或开玩时会检查并应用。状态文字中的“128 chunks/region maximum”只是预算说明，不再误报为超限。

### 旧草稿拖不动时

- **黄色角标**只是问题范围，不是盒子、房间或控制器；不会响应点击拖动。路径上的编号方点才是节点，橙色小点是切线手柄。选中空间、上一/下一节点、定位问题都会将变换轴切到真正的节点，不再错误地拖动整个通道 Actor。
- 旧草稿本来就非法时，正常安全编辑会拒绝仍然非法的中间步骤。点击 **修复旧草稿**，才会显式进入一次性的轮廓修复模式：允许分步拖动并保留中间轮廓，未完成前不能开玩，保存也明确标为草稿。它不是“每步合法”模式，界面会持续标明。
- 整个布局通过形状、连通、布尔、碰撞和预算检查后，地形一起更新，并自动退出修复模式，恢复每步合法的安全约束。
- **取消修复**恢复进入本次修复前的节点、截面和关联房间等设计数据；修复步骤支持撤销/重做。不要在修复中从大纲删除 Actor；取消只能恢复仍存在的对象，被删除对象需用撤销找回。
- 支线房间支持整体变换和六面手柄编辑。房间绑定的通道端点跟随房间；直接拖动入口节点会沿绑定墙面滑动，不能拖离该墙面。移动整个房间时先选“移动空间”，再用 W。

安全基线在编辑器会话中维护，换图重新检查。没有关联生成器的独立空间只验证自身形状，会显示“尚未生成可运行地形”。原生大纲删除、外部脚本批量新增等非工具操作若破坏引用，会明确标为未应用，需撤销删除/新增或重新连接，不把旧实体误报为新结果。优先使用工具内的新建、连接和控制点编辑。

撤销历史记录设计输入，而不是每一步生成的临时岩石。撤销/重做恢复输入后重新生成，避免旧组件挂接记录与新地形冲突。

为保证每次接受的修改都能生成，当前采用同步检查和重建；复杂布局拖动时可能有停顿，本次没有实现异步或增量生成，也没有提高运行时预算。旧二维工具的防抖机制不变。

**开玩检查**：PIE 和模拟运行前再按当前设计完整同步一次。失败会留在编辑器，提示原因并聚焦问题，不再静默进入上一版地形。保存/开玩检查只接受完整合法的设计，不会自动缩小截面或挪动节点来让检查通过。重新生成可能需要短暂等待；这项防护针对编辑器内运行，不会更新已经打包的旧游戏。
