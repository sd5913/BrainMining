# FullJourney 通路切割体与堵塞层生成提示词

本提示词依据 2026-10-13 当前 `/Game/Campaign/Maps/Lvl_FullJourney` 的矿区配置、关卡导航路线及有效阻塞层读取结果编写。只描述矿道模型，不执行生成或修改关卡。

## 当前版本与之前的区别

- 之前是约 530.36 米的完整下降主路和 7 条支路。FullJourney 从原主路中截取三段并按 0.5 缩小：Mine01 取原弧长 4–126 米，主道本体 61 米；Mine02 取 174.5–279 米，本体 52.25 米；Mine03 取 395–459.6 米，本体 32.3 米。三段本体合计 145.55 米。关卡导航路线含洞口和短接段，分别约 74.6、63.8、46.0 米，下降约 21.0、18.0、10.9 米。
- 原宽度与高度随整体尺寸约减半。旧版名义横向宽度 5.4–19.17 米，缩小后参考量级为 2.7–9.6 米；实际口部另有局部形变，尺寸应以当前净空为准。裁切后仅保留对应范围的支路/侧袋，不是完整的七支路布局。
- 新版增加了矿道自身的入口、出口短接段及自然岩面过渡。内外口部、顶部和侧面经过局部形变，减少平直矩形切口；新增的岩层和附近主岩层一起处理，以避免接缝。这些变化烘焙在关卡的 GeneratedMiningRock 中，没有反写旧 Static Mesh 通路切割体。
- 旧加厚版是 20 个独立阻塞块，原完整通路中的体积占比为 49.64%。当前三段各保留 20 个引用，共 60 个引用，但只有 16 个对象非空：Mine01 为 6 个、Mine02 为 5 个、Mine03 为 5 个；其中包括裁切剩下的小边角。当前填充比例未重新按三段有效空腔核算，不能沿用旧版 49.64% 当作现状。

## 可直接使用的提示词

请在 Blender 中，依据 FullJourney 当前三段矿道的实际空腔形状，生成用于 UE 布尔差集的通路切割体，以及与其精确贴合的独立堵塞层。

【范围与参考】
仅生成 Mine01、Mine02、Mine03 三段矿道本身，包括矿道内部、保留下来的短支路/侧袋、矿道自身的洞口与短衔接段。忽略拼接进来的电脑房、回声/卡牌/电视场景、博物馆、结局场景及其中所有建筑、地板、门、家具、道具。房间只可提供洞口对接坐标和朝向，不输出其模型，也不补造跨过房间间隙的长隧道。

使用 `Docs/FullJourney_TunnelRoutes_20261013.json` 的三条矿道路线作为空间基准，保持它们的相对位置、旋转、尺度和起止点。截面及口部形状以当前关卡烘焙岩层的真实空腔为准；旧通路 Static Mesh 仅作为造型参考。已有 `Art/Mining/FullJourneyExchange/FullJourney_Editable.blend` 可作空间参考，只参考矿道相关岩层和非空阻塞块，排除房间、道具及外围土层。不能把烘焙岩层本身直接当成空气切割体。

【三段通路】
1. 三段分别建模，每段内部连续完整，三段之间保持现有布局和间距。主道本体长度约 61、52.25、32.3 米；矿道洞口和短衔接段另计，含这些短段的路线参考长度约 75、64、46 米。
2. 每段从较高入口向较低出口延伸，总体持续下降；保留横向蜿蜒、局部转折和三维高度变化。必要的口部水平过渡要短，不增加逆坡、上升回环或新的长支路。
3. 截面以圆形、椭圆及自然岩洞轮廓为基础，宽窄连续变化。横向宽度量级约 3–10 米，局部宽段可达窄段的 3–4 倍；以实际参考净空为准，不再次整体加宽。窄段及口部须足够容纳约 2 米高的角色，保留合理头部与肩部余量。
4. 保留当前裁切后实际存在的短支路和侧袋。主路与支路在交汇处做几何并集和圆滑过渡。不要恢复旧版完整七支路，也不要新增回接、意外交叉或贯通。
5. 洞口和短衔接段形成自然、不规则的岩石开口：下部保持通行净空，上部有圆润拱形及适度起伏；与矿道内部连续过渡，避免突兀的矩形切口、尖锐台阶和明显接缝。只表现矿道口部，不生成房间的建筑门框。

【切割体与 Lowpoly 表面】
通路切割体是占据未来空气空腔的实心封闭模型，不是洞壁壳。只生成空腔填充实体，不生成外围岩体、墙体厚度、地形盒或藏品土层。所有端部封口，支路末端自然收束。

模型表面就是未来洞壁的几何边界。在表面直接做 Lowpoly 岩石起伏、大小不一的折面和局部凹凸，风格接近《深岩银河》。弯曲和宽窄变化保持连续，避免密集尖刺、尖锐夹角和影响通行的大凸起。岩石风格必须来自几何形状，不依赖贴图或 UE 材质效果。

【对应堵塞层】
1. 先完成最终通路切割体，再依据它生成堵塞层。以当前三段的主要有效阻塞位置和密度为参考，而不是复制 60 个对象引用；不要用空对象或裁切碎片凑数量。
2. 当前非空对象数量 6/5/5 可作为三段布置的起点，但小边角残块应清理、合并到合理阻塞区或省略。数量与长度允许调整，以完整封堵、间隔可读和末端安全为准。
3. 沿用之前的设计目标：所有阻塞块合计约占三段有效矿道空腔体积的 50%，允许约 45%–55%。按实际实体体积核算，不按对象数量、包围盒或路径长度替代。此项是新版生成目标，并非对当前关卡比例的描述。
4. 每个阻塞块完整封住所在截面，并沿该段的弯曲方向延伸。与最终通路切割体做精确布尔交集，保证侧面贴合洞壁，没有可绕过的边缝，也不伸入外围岩体。露出的两端做成不规则 Lowpoly 岩面。
5. 相邻阻塞块之间保留明确的空腔，挖穿一个块后能进入下一段可见空腔。入口、出口、洞口衔接区、支路分叉及所有死端前留空。每条通路最后一个阻塞块后至少保留约 3–5 米连续空腔；空间允许时增加留空距离。禁止让阻塞块贴住最终封口，或一直填充到终点而没有下一个洞口。
6. 不用简单整体拉伸旧阻塞模型来加厚。宽度、厚度及弯曲需根据新通路重新构建；不得堵住相邻支路、意外连成一整段实心矿道或遮盖洞口。

【几何验证与交付】
每段切割体和每个阻塞块均须封闭、法线一致，无重复面、零面积面、非流形边、内部重叠面及意外自交。将制作过程中产生的接缝和内部重复封口面清理干净。验证各阻塞块完整封堵截面、挖穿后存在下一段空腔、所有出口和死端前保持留空，并输出实际填充比例。

交付 `FullJourney_Tunnel_Cutters.fbx`，只包含三段通路切割实体；另交付 `FullJourney_Blockers.fbx`，只包含独立堵塞模型。两个文件使用相同原点、坐标轴和单位，保留当前三段布局，不分别居中。Blender 用米制，坐标按 `(UE.X, -UE.Y, UE.Z) / 100` 对应 UE 厘米。保留可编辑 `.blend`，切割体、堵塞层与仅供参考的模型分集合；参考模型不导出。对象名包含所属矿段和序号。
