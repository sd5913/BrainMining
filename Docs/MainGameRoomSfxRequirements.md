# MainGame 主房间玩法与音效需求单

核对日期：2026-10-16。代码基线：`e15b351`。目标地图：`/Game/MainGame/Maps/Lvl_MainGame`。

后续实施记录见 `Docs/MainGameRoomAudioImplementation.md`：71 个声音已导入并核验，原生事件接入代码已编译，18 项自动化测试通过；逐房间听感验收待进行。本文保留实施前的需求基线，表内“新增／已有”等状态描述对应上述基线。

## 1. 核对范围与结论

本单依据当前 MainGame 配置、连续关卡的源房间接入代码、玩法状态机、现有声音调用与磁盘资产核对。当前用户正在运行 UnrealEditor，资源保护拒绝另起编辑器读取地图；本轮没有关闭用户编辑器，没有重新加载用户当前场景，也没有进行逐房间实玩或听感验收。房间实例若有未保存修改，不在本次证据范围内。下述可编辑计时是代码默认值，接入时应读取房间实例参数。

当前主线：**卧室教学 → 第一矿区 → 电脑办公室 → 第二矿区 → 回声迷宫／巨人牌局／电视逃生 → 第三矿区 → 镜像博物馆。**

- MainGame 配置包含三个主房间源地图；Journey 一组内含三个连续玩法。卧室作为教学空间单列。
- `Docs/MainGameRooms.md` 开头仍保留旧四矿区流程。本单以 `Docs/MainGameSystems.md`、`Config/MainGameRooms.json` 与当前接入代码为准，第四矿区和细胞／宇宙结局不列入本轮房间音效范围。
- 三矿区已统一的 Dreamy Flashback 音乐保持现状。`MiningAudioMainGame.cpp` 对非 Mining 区域返回 `INDEX_NONE`，矿区音乐与环境层会淡出；这不等于办公室、牌局、博物馆已经有专属配乐或环境声。
- 回声插件有 4 个、牌局插件有 7 个明确的声音资产及播放调用。生成脚本表明它们原本是程序合成的基础音效；本轮未试听，不能据此断言当前音色质量。
- 办公室、电视逃生编排和镜像博物馆的已核对原生实现中，未找到完整的专属声音调用。玩家共用的挖掘、移动、炸弹等音效仍可出现，不能把整个房间称为完全无声。

### 资源清单的读法

- **P0：玩法必需。** 先让玩家听懂动作是否成功、危险是否开始、下一阶段是否开启。
- **P1：体验完整。** 补物理过程、空间层次和表演节奏。
- **P2：后续润色。** 环境细节与可选角色表演，不阻塞首轮交付。
- **已有**＝找到资产与原生播放调用，不代表本轮已听验；**补接／复用**＝有可借用素材，但该事件仍需接线；**新增**＝需要专属事件与素材；**拆分**＝现有一段声音不能清楚覆盖多个语义。
- 下表每行是一个事件需求，不等于必须下载一个新文件。共享点击、成功、失败、石块、爆炸等可以复用，循环可通过参数分层。
- 时长、变体和并发是本单建议的首轮制作规格，不是已经实现的参数。2D 用于 UI／明确提示，3D 用于可定位的实体声源。

## 2. 各房间实际玩法

| 空间 | 当前实现的操作与流程 | 音效必须表达的内容 |
|---|---|---|
| 卧室教学 | 接近并瞄准装备按 E，分别取得镐子和喷气背包；挖开出口，使用喷气通过连接竖井。装备可任意顺序拾取；未拿齐时 G/V/Tab 被教学限制 | 装备取得、挖掘有效、喷气点火与停止、落地 |
| 电脑办公室 | MainGame 入区启动办公；2 台电脑和 2 台打印机独立产生待处理任务。E 进入电脑、鼠标回复弹窗；E 处理打印纸。任务按时间加速，随后弹窗与纸张喷发，出现可拾取炸弹；用真实炸弹炸开出口，走出后封闭回路并触发办公室爆炸坍塌 | 哪台设备需要处理、处理成功、系统失控、炸弹出现与拾取、门确实炸开、撤离后坍塌 |
| 回声迷宫 | 踩入触发区后地板坍塌并下落；落地首次显影，左键敲击产生短暂轮廓，玩家据此探路；接近暖光洞口后切回真实挖掘，挖大洞口进入巨人房间 | 坍塌与落地、每次有效敲击、脉冲消散、从黑暗到暖光空间的转变 |
| 巨人牌局 | 沿纸箱、书本、尺子上桌或飞上桌，E 入座并开始匹配。固定四回合：激光；毒；火＋激光点燃残留毒气；剩 1 HP 后打出全部 17 张牌终结。每回合需将手牌全部选中才能确认。对手飞出撞墙，胜利后收集彗尾法球 | 选牌、出牌、三种技能及组合、反击、濒危、终结与撞墙、奖励拾取 |
| 电视逃生 | 对手撞墙先破开缺口；领取法球才进入 Warning，再开始涨水。利用家具和飞行到电视，及时到达后建立电视检查点；挖开屏幕及内部连续岩段，按顺序穿过各段并到达出口。淹没、超时或短路会失败，并从对应检查点重试 | 预警与涨水、电视方向、检查点、屏幕破坏、内部电气危险、失败类型、重试与逃脱 |
| 镜像博物馆 | E 思考物体，把最多两个对象放入气泡；G 编辑，拖动红色属性词交换，Q/R 关闭对应气泡。普通、沉重、悬浮、可穿过、导电、大、小改变物体或镜中自己的属性；用沉重压块完成压力机关，让陶瓷球缩小落下后获得导电属性完成电路；两锁同时满足后开启奖励小门，缩小自己进入奖励凹室完成 | 思考录入、交换成功／拒绝、属性变化、实体移动／落地、两种机关分别成立、开门、最终完成 |

### 不应混入需求的旧规则

1. 办公室的回复和打印仍推进交互，但 MainGame 不再发金币或矿石；不要播放金币收入声。
2. 办公室进入失控阶段依赖时间，不依赖清空全部弹窗；不要把失控包装成玩家操作失败。
3. 牌局是固定剧情回合，不是本轮需要制作洗牌随机战斗、抽卡稀有度、牌组编辑或随机输赢的一套系统。
4. 电视逃生不是牌局结束立即满水：撞墙、领奖、预警、涨水、电视检查点是不同事件。
5. 博物馆本轮是镜像属性交换机制，不应套用项目里其它 WenSi 原型的全部拼字或电路玩法。

## 10. 已有资产与需要特别防止的漏接

### 已有音源，不必重复采购

- `/Game/Passages/Echo/Audio`：`S_Crumble`、`S_Landing`、`S_Knock`、`S_Exit`。
- `/Game/Rooms/CardDuel/Audio`：`S_Arrival`、`S_Draw`、`S_Laser`、`S_Poison`、`S_Finale`、`S_Impact`、`S_Reward`。
- `/Game/Audio/MainGame` 与 `/Game/Audio/Pilot`：装备取得、脚步、挖掘、钻机、喷气、玩家炸弹、收取和升级反馈已有基础，优先复用事件与分层素材。

### 接入风险

1. **办公室炸弹拾取提示会漏触发。** `MiningCampaignRooms.cpp` 在 MainGame 初始化时已设置 `bBombSkillUnlocked=true`；`UnlockSkill` 仅在首次解锁时广播 `OnSkillUnlocked`。办公室领取仍能成功，专属领取音应绑定 `FPopupOfficeExit::Collect` 的成功结果，不能只监听解锁广播。
2. **装饰爆炸不自动继承玩家炸弹声。** 办公室尾声直接创建 `AMiningBombExplosion` 视觉对象；真实玩家炸弹的播放在 `AMiningBombActor::PlayBombSound`。需给尾声轮次单独编排声音，不能只看见爆炸特效就认为已有音频。
3. **牌局与逃生不能重复播撞墙。** `OnOpponentWallImpact` 通知逃生破墙；二者只指定一个声音负责方，保留同一准确时刻。
4. **属性交换成功不等于机关完成。** 博物馆应按位移到位、电路条件和最终拾取的状态边沿触发，不能都绑在 `SwapWords` 上。
5. **回声的固定尾音不等于真实方位导航。** 当前声音生成脚本使用固定延迟叠加；视觉轮廓负责主要探路。未增加墙距／方位检测前，不宣称玩家能仅靠回声判断正确出口。
6. **不要根据 Tick 每帧播放。** 警告、压力、电力、检查点和完成音均需要一次性状态变化；循环只创建一次并更新音量／参数。

## 11. 制作、接入与验收规格

### 建议素材交付

- 母版建议保留 WAV、48 kHz、24 bit；实际导入格式按项目流程处理。空间点声源优先单声道；2D 宽声场和环境床可用立体声。
- 高频重复动作优先准备 3 个以上变体；关键剧情提示可先 1 个。循环需要干净接缝，长机械／水流最好提供起音、循环、停音。
- 留出混音余量；试听时以真实场景中的脚步、钻机、喷气和剧情声共同播放为准，不用单独文件听起来很响作为通过条件。
- 建议新增目录 `/Game/Audio/Rooms/Office`、`Echo`、`CardDuel`、`Escape`、`Museum`，但已有插件资产不必搬家；避免改路径破坏现有加载。
- 如之后寻找免费素材，逐条记录作者、来源页、原始文件、下载日期、许可证、署名要求、剪辑／合成方式。此需求单没有执行新的下载或宣称已完成授权审查。

### 分组与并发建议

| 声音组 | 路由 | 建议首轮控制 |
|---|---|---|
| 动作、机关、危险提示、UI | Effects | 按事件与房间分组；关键预警不可被纸张／牌面声挤掉 |
| 室内风、电气底噪、非关键水体背景 | Ambience | 同房间少量层；注意危险涨水的核心提示仍放 Effects，避免玩家关环境声就失去预警 |
| 后续如制作角色语音 | Voice | 不作为唯一解谜／逃生信息；文字与状态提示保留 |
| 现有矿区音乐 | Music | 保持当前三矿区统一音乐；本单不改配乐方案 |
| 办公室通知 | Effects | 每台设备冷却并限制全房间总并发；喷发高峰用循环层替代逐粒播放 |
| 牌局末回合 | Effects | 17 张牌合成一个成组动作；发射、命中、飞出、撞墙按时序排列 |
| 房间退出及重试 | 各对应分类 | 停止旧循环、释放播放器；重试后只重建当前阶段需要的声音 |

### 首轮验收

1. 办公室：每次真正回复／处理纸张有反馈；自动删弹窗不冒充成功；炸弹已解锁仍有拾取声；破门只在成功时响；离开后坍塌声有来源方向。
2. 回声：敲击和轮廓出现对齐；冷却期间不重复出声；首次落地避免两个大冲击叠加；退出后不残留迷宫循环。
3. 牌局：选牌与撤牌可辨；第三回合听出组合技；第四回合不因 17 张牌出现音量突增；对手撞墙与破口同刻；胜利与领奖有区别。
4. 逃生：领奖后才进入预警；到检查点前后的危险节奏正确切换；淹没与短路可辨；失败后旧警报停止；重试两次不叠水声；真正逃脱后警报结束。
5. 博物馆：同对象重复 E 不刷提示；词语交换拒绝不播放成功；机关声等待物体实际到位；压力和电力两声可辨；开门不提前播放最终完成；重置后声音状态也恢复。
6. 全局：F8 分类和总音量生效，暂停和地图切换没有残留循环；跨区往返不叠播；矿区统一音乐不被房间音效改回旧分区曲目。
