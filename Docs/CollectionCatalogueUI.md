The collection catalogue follows the supplied `G (3).png` layout with a grey
translucent trapezoid, dark right-hand description area, green owned slots,
unknown question-mark slots, and native vector navigation/return icons.
`SBackgroundBlur` applies Gaussian blur to the underlying scene; the isolated
HDR item capture is displayed through a translucent UI material with inverse
opacity, so its background does not cover the grey panel.

Hovering slots/arrows/return highlights them. Left/right arrows and keyboard
arrow keys cycle all four entries, including unknown ones. Slot clicks select
an entry. Drag rotates an owned item, wheel zooms, double click or F resets.
The return icon uses the configured catalogue key (Tab by default); clicking
it, Tab or Escape closes the catalogue and restores movement/mining input.
Only entries actually in inventory are green and show their model/description.

The migrated heaven collectible's preview uses the same authored toilet mesh.
Other collection scenes retain their existing models and inventory semantics.
