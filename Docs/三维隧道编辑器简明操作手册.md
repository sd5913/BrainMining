# 三维隧道编辑器 · 简明操作手册

适用：当前“自由编辑 + 全场景统一基岩外壳”版本。

**记住这个顺序：摆房间 → 拉通道 → 调边界 → 加空洞 → 检查 → 保存。**

## 1. 打开工具

1. 在内容浏览器打开 `MiningPrototype / Maps / Lvl_MiningSpatial_Demo`。
2. 点击菜单 **工具 → 三维隧道编辑器**，再点 **总览全图**。
3. 点击场景里的空间，或用面板的 **选择空间 / 矿区** 选择对象。

编辑时保持 **空间灰模预览** 开启，更容易看清通道和房间。

## 2. 常用操作

| 我想做什么 | 怎么操作 |
| --- | --- |
| 移动整个房间或通道 | 选中对象 → **移动空间** → 按 **W**，拖动坐标轴。 |
| 改房间大小 | 选中房间，拖六个面的**青色控制柄**；另一面不动。 |
| 拉弯通道 | 选中通道 → **拉通道走向** → 拖**白色节点**；绿色 **+** 用来加点。 |
| 调整两侧边界 | 选中通道上的节点 → **勾画边界 → 正对截面** → 拖白点画轮廓，或拖青色柄调单侧宽高。 |
| 扭转通道 | 选中节点 → 展开 **高级编辑** → 调整 **扭转°**。 |
| 增加空洞 | 先选通道上的节点 → **+可编辑空洞** → 移动到想要的位置，再勾画边界。 |
| 增加支线房间 | 先选通道上的节点 → **+支线房间** → 摆好位置和大小 → **选中房间连接主通道**。生成的支线还可以继续拉弯。 |

- **三维方向不好控制？** 展开“场景总览与视角”，切换顶视、正视或侧视；直接拖点主要沿当前屏幕平面移动。
- **操作错了？** 点面板的 **撤销**；正在拖动时按 **Esc** 取消本次拖动。
- 主房间先只改位置和大小；需要旋转的房间使用支线房间，选 **移动空间** 后按 **E**。

## 3. 基岩不用手动搭

在 **全场景岩体与统一基岩（厘米）** 中，保持“整个场景共用基岩外壳（房间之间可挖）”和“自由编辑”开启。

**整个场景是一大块可挖岩体，房间、通道、空洞是里面的空白；只有场景最外围有基岩。房间之间没有预设通道，也能自己挖通。**

| 参数 | 简单理解 | 默认值 |
| --- | --- | --- |
| **场景外扩余量** | 在所有空间的总范围外再留多少岩石；不是每个房间各套一层。 | 400 cm（4 米） |
| **基岩厚度** | 最外层不可破坏外壳的厚度，不是可挖深度。 | 100 cm（1 米） |

外围会跟随全部空间的位置自动生成一个总盒状边界，**不用再拉矿区盒子**。这两个参数会同步整个场景的矿区；内部技术分块不是基岩墙。游戏中基岩不会跟着玩家挖掘向外移动。

## 4. 查看效果、保存、试玩

1. 点击面板上方 **检查并重建**，等待后台生成结束。
2. 关闭 **空间灰模预览**，查看实际岩体；若仍隐藏，在高级编辑里点 **显示岩石**。
3. 确认状态显示地形已经应用，再点 **保存当前关卡**，查看保存反馈。
4. 点击 UE 的 **播放** 试玩。

**“已保存”不等于“地形已生效”。** 报错的草稿也能保存，但需要修好并重建成功才能试玩。

## 5. 出问题先这样做

- **看不到自己在编辑哪里：** 点 **总览全图** 或 **聚焦选中**。
- **拖完出现报错：** 点 **定位生成问题**，按提示修改局部；造型会保留，不用从头搭。
- **提示超过分块预算：** 先减小 **场景外扩余量**，检查是否有空间被拖得过远；仍超限再拆分矿区，不要盲目增加厚度。

第一次练习只做三件事：**移动一个房间、拉弯一段通道、加一个空洞**，检查成功后再继续扩建。
