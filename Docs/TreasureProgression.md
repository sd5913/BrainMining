# 矿物大小、价值与四线养成

规则来源：飞书《HUD、宝物与养成【可推进】【P1】》，2026-10-12读取的宝物表第73～81行、养成表第93～108行，以及本次用户确认的“同种矿物四个大小对应四档价值”。

先根据区域和权重抽取类型，再等概率抽取四个大小档之一；固定种子可复现。每个实例的 SizeTier 同时决定 ValuesBySize 中的基础价值和 SizeMultipliers 中的模型倍率。尺寸暂定为该矿物 Scale 基准的 55%、70%、85%、100%，属于本次展示默认值，不是文档给定的厘米数，也不是按金币价格直接等比缩放。

这四个倍率与价值均可编辑，但必须四项齐全、递增且大于零。旧地图中的内置矿物ID 1～9会在加载时补上缺失的四档价格，不覆盖已有美术与生成配置。每档都使用缩放后的实际碰撞和表面采样判定埋藏、暴露与领取范围，仍要求暴露严格大于50%、准星命中且不隔墙。

基础价值生成后不再改变。主关卡镐子四级有50%概率令本次领取金币翻倍，CollectedValue记录实际收益；提示显示翻倍，但模型不变大。已领取物体不能再次结算，恢复岩石不复活宝物。独立旧展示地图仍使用自己的展示金币，四条养成在主关卡启用。

矿物暴露超过50%后，在可释放的空间内轻微弹出并开始物理下落、翻滚、落地。掉落只改变位置与朝向，不改变尺寸档位、基础价值或翻倍概率。可以在空中或地面瞄准按E领取。离开展区暂停运动，返回继续；R恢复岩石会重新埋藏尚未领取的矿物，已领取矿物不复活。掉落验收脚本为 Scripts/verify_treasure_drop.py。

当前六区仍是分别展示的原型：矿物庭院保留两排各九个槽位。文档中的四个正式矿区、具体刷新区域和权重尚未填写，本次没有擅自配置正式分布或调整庭院密度。

## 四条养成线

按住Tab显示四项，每项四级，逐级扣除共享金币。卡片显示名字、当前等级、下一等级效果及价格，余额不足显示红色价格并禁用购买，满级显示MAX。升级配置位于 BP_SharedMiningCharacter 的 Progression 组件：Tracks / Steps 的 Price、Effect、Value、SecondaryValue、Description。

| 能力 | 四级价格 | 依次获得的效果 |
| --- | --- | --- |
| 镐子 | 50 / 1000 / 5000 / 50000 | 深度×2；范围×2；间隔×0.5；收矿50%概率金币翻倍 |
| 喷气背包 | 250 / 7500 / 25000 / 125000 | 散热等待×0.5；散热速度×2；最大热量×2；创造飞行 |
| 炸弹 | 1500 / 10000 / 40000 / 160000 | 自动补充时间×0.8；容量×2；破坏范围×2；容量再次×2且引信×0.5 |
| 钻机 | 20000 / 100000 / 500000 / 2000000 | 恢复速度×1.5；储量×1.5；消耗速度×0.75；无限能量 |

每级效果累计，重新进入区域或绑定界面时从初始能力计算，不反复叠乘。购买失败不扣费，也不会跳级或购买第5级。金币、等级与当前资源在本次游戏会话内跨区保留，未加入磁盘存档。

镐子深度升级保持横向半径，沿命中表面的法线向岩体内部延长挖掘；第二级再扩大半径。钻机沿用现有更快间隔和更大半径倍率。

喷气背包的自然散热等待默认1秒，一级后0.5秒；二级增加散热速度，三级扩大容量时保持每秒产生热量不变。创造飞行保留碰撞：空格上升、松开悬停、左Ctrl下降，WASD水平移动，不积累热量。剧情中的禁飞规则仍生效。

主关卡炸弹默认3枚，每10秒自动补充1枚，一级后8秒；容量为3→6→12。投掷成功才消耗，空库存不生成炸弹，库存满时不积攒额外恢复进度。容量升级不会凭空补满库存。G装备、左键投掷，HUD显示当前/最大数量；已有物理、爆炸特效和模型保留。

主关卡钻机改用能量：默认容量100，基于原使用/冷却时长计算消耗和恢复（原配置10秒/10秒对应每秒10点）。装备期间消耗，收起后恢复；面板交互时暂停消耗。V可在有能量时装备，再次按V收起。升级后恢复15点/秒、容量150、消耗7.5点/秒；满级无限。V图标显示能量百分比或∞，切换工具不重置能量，R重置岩石不补满能量或炸弹。未启用主关卡养成的独立地图保留旧钻机计时模式。

## 验证

- BrainMining.Treasure.RulesAndWeights / ExposureAndGeneration：九类四档网格的采样、大小价值对应、全埋藏、暴露门槛、种子与区域权重过滤。
- BrainMining.Progression.RewardsAndResources：翻倍概率边界、扣费拒绝、不同帧率下的资源恢复和消耗、创造飞行与剧情禁飞。
- Scripts/verify_treasure_progression.py：主地图实际Tab面板点击16次升级，核对每级价格与效果、拒绝重复与跳级、跨区保留、真实悬停/下降、无限钻机和炸弹投掷。
- Scripts/verify_main_treasure_access.py：正常入口步行、实际挖掘、E领取与返回；用于保留此前修复的步行路线。
