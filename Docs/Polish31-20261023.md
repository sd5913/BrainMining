# 退出确认与平行菜单按钮（2026-10-23）

Windows Esc 暂停菜单移除退出游戏，仅保留继续游戏、查看藏品、设置、保存进度、返回主界面。谢幕后的 Esc 同样进入该暂停菜单，不直接弹出退出确认。

主界面点击退出游戏先弹出“确定退出游戏？”，提供“取消 / 确认退出”，默认焦点为取消。Esc 或默认回车会取消并恢复主界面焦点、鼠标状态；只有确认退出才终止程序。弹窗与取消不会写入存档，也不会解除初始镜头的控制锁。保留现有移动端暂停确认行为。

三个按钮统一采用开始游戏的 +7° 角度和 +10° 斜切，文字从左上向右下倾斜并彼此平行；继续、开始、退出的水平偏移仍为 +18 / +4 / -12，保留从上到下向左错落及整体避开椅背的位置。
