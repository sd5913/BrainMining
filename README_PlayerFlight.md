# 跳跃与喷气背包

喷气背包采用「普通跳跃 → 点火蓄升 → 爆发上升 → 松手收势 → 持续加速下坠」的节奏。参考用户提供的 `D:/video/2026-10-15 15-12-04.mp4`；参数针对本项目调校，不是对参考游戏物理参数的精确复刻。

## 操作

- 短按空格：立即普通跳跃，不点火、不产热。普通跳跃保留原来的跳跃高度倍率。
- 首次持续按住 0.22 秒：开始喷气；先轻推，再在 0.28 秒内快速增强至爆发推力，持续按住可持续上升。
- 短按松开后 0.30 秒内再次按下：立即点火，按住继续上升。超过窗口则需要重新长按。
- 喷气上升时松手：保留向上惯性，在约 0.50 秒内完成收势到下坠的过渡。前 35% 时间柔和收住向上惯性，后 65% 用平滑曲线恢复重力、退出阻尼；不再在计时结束时突然切换。阻尼只作用于向上运动，过顶后持续加速下落。普通小跳、过热和仍在下坠时松手不触发滞空。
- 下落时再次按空格：立即点火并刹车，不需要长按等待或连按窗口；从平台走落后的第一次按键也生效。高速下降时强力制动，接近低速区时刹车连续减弱，再以小推力从缓缓下沉经过零速到轻微上浮。默认约 0.30 秒经过 -60 至 +60 cm/s 的低速区，速度始终变化，不会固定悬停；随后用 0.32 秒平滑增强至满推力。低速段计时从进入该区间开始。速度随人物缩放变化；较低推力设置下会相应缩小速度区间。已喷气后仍在上升时再次按下，保留即时补推。松开补喷则取消后续推力增强，恢复原来的收势与下落。按住补喷低速滞空仍消耗正常热量。
- WASD 在空中继续控制方向；胶囊碰撞、地板、墙壁、天花板均保留。
- 满热仍锁定 3 秒，强制结束上升与滞空；按键不能绕过锁定。热量仅在点火后增加，普通跳跃不会显示喷气热量仪表。
- 落地、R 重置、失去控制、剧情禁飞和脚本传送清除点火、连按窗口及滞空状态。重置后需松开空格再按。
- 满级自由飞行保留原来的空格上升、Ctrl 下降、松手悬停模式。

## 调参

停止 Play，选中当前关卡唯一的 `MiningTunnelGenerator`，展开 **Player Flight → Jetpack Feel**。也可在 **工具 → 矿业策划台 → 角色与飞行** 调整中文参数。下次 Play 生效，不需要重建地形。

| 参数 | 默认值 | 作用 |
|---|---:|---|
| Hold To Ignite Seconds | 0.22 s | 长按点火阈值 |
| Double Tap Window Seconds | 0.30 s | 短按松开后的二次点火窗口 |
| Spool Up Seconds | 0.28 s | 点火到爆发的蓄升时间 |
| Air Catch Hang Seconds | 0.30 s | 补喷从缓缓下沉过渡到轻微上浮的低速时长，不锁定零速度 |
| Air Catch Rise Seconds | 0.32 s | 低速段后，向上推力从轻推平滑增强到满推力的时间 |
| Initial Thrust Fraction | 0.18 | 初始推力占原有加速度的比例 |
| Boost Speed Multiplier | 2.4 | 原有上升速度的倍率 |
| Boost Acceleration Multiplier | 2.6 | 爆发推力相对原有加速度的倍率 |
| Release Hang Seconds | 0.50 s | 松手后收势至完整下坠重力的过渡时长 |
| Hang Gravity Multiplier | 0.18 | 过渡初始重力倍率，随后平滑增强 |
| Hang Drag | 7 | 仅收住向上惯性，随过渡退出，不减缓下落 |
| Fast Fall Gravity Multiplier | 2.8 | 喷气后快落阶段的额外重力倍率 |
| Fast Fall Speed Multiplier | 5 | 提高喷气后限速，留出持续加速空间 |

当前基础参数：Ascent Speed=450、Lift Acceleration=1500、Max Fall Speed=650、Air Move Speed=500、Fall Gravity Multiplier=1。新倍率作用于关卡已保存的基础参数，旧地图不需要迁移或重存即可获得新节奏。

全部默认值下，缩放前爆发上升上限为 1080 cm/s，净加速度峰值 3900 cm/s²，快落上限 3250 cm/s（上一版为 1300）。竖直速度与加速度仍跟随 Player Scale；水平速度同时跟随 Movement Speed Multiplier。Player Scale=0.7 时，上升上限 756 cm/s、快落上限 2275 cm/s。若旧关卡手动保存过 Fast Fall Speed Multiplier=2，请在关卡设置中改为5或恢复默认值。

没有生成器的旧模板关卡沿用角色蓝图设置；多个生成器时也沿用角色设置并输出警告。禁用喷气背包恢复普通跳跃。当前是单机实现，没有网络推力输入预测或复制。

## 验证

`BrainMining.Flight` 自动化覆盖短按、连按窗口、长按点火、蓄升与爆发、惯性滞空、快落、空中补推、热量锁定、重置与禁飞、非法参数、人物缩放以及 15/30/60/120 Hz。

`BrainMining.Flight.CharacterJumpCoastAndCollision` 在独立测试世界中使用主游戏角色蓝图与真实 CharacterMovement，检查短按起跳、长按升空、松手滞空与快落、地板/天花板碰撞和失去控制清理。

新增 `BrainMining.Flight.SmoothReleaseAndAcceleratingFall` 检查滞空结束处的加速度连续性、长落持续增速、15/30/60/120 Hz 轨迹差异，以及物理分步不会重复推进滞空时钟。角色碰撞用例另检查 3250 cm/s 下落时仍能正常落地。

`BrainMining.Flight.AirCatchAndRepeatedReignite` 覆盖不同下落速度、人物缩放和 15/30/60/120 Hz 下的立即补喷、减速耗时与掉高、低速段持续时间、全程速度变化没有静止平台、连续三轮松手下坠再起飞、物理分步一致性，以及过热/禁飞不能被空中补喷绕过。真实角色用例另从离地 350 cm、速度 -3250 cm/s 的状态按空格，验证触地前减速、低速段速度和位置仍变化、然后恢复上升。`BrainMining.Flight.CatchHoverInterruptions` 检查补喷低速段仍产热，松手、过热和重置会取消后续推力增强。
