# 手柄震动

震动由本地玩家的 MiningHapticsSubsystem 管理，与音量和音效播放独立。使用 UE 动态 Force Feedback 的大、小马达通道；Windows XInput 将大通道映射到低频马达、小通道映射到高频马达。没有使用扳机专属震动。

## 玩家设置

暂停菜单 → 声音与震动，或 F8 打开设置。支持手柄导航和鼠标操作；较小窗口可滚动。

| 设置 | 默认值 | 行为 |
|---|---|---|
| 震动总开关 | 开 | 关闭时立即停止，拒绝后续效果 |
| 震动强度 | 75% | 对所有效果统一缩放；0% 停止 |
| 钻机与喷气持续震动 | 开 | 同时控制结尾钻进；不影响命中和奖励短震 |
| 轻微交互与演出提示 | 关 | 开启后提供炸弹装备、钻机微弱空转、交换拒绝、办公室警报、标题落墙提示 |

设置保存在 Saved/Config/BrainMiningHaptics.ini，与音量配置分开。恢复默认音量不会改变震动偏好。

## 触发清单

强度是预设峰值，实际输出还会乘以总强度、事件强度与距离衰减。所有短震最长 0.5 秒。

| 机制 | 接入时机 | 控制方式 |
|---|---|---|
| 镐子命中 | MiningPickaxe 的真实接触 | 短震；按开凿阶段轻微增强 |
| 镐子破碎 | 最终阶段的开凿完成通知 | 覆盖同次普通接触 |
| 不可挖表面 | OnMiningBlocked 同位置 | 0.2 秒节流；挥空不震 |
| 钻机启动 | bDrillMode 从关闭变为开启 | 一次启动短震 |
| 钻机开凿 | 实际成功命中且正在操作 | 细密连续震动，接触超时自动淡出 |
| 钻机空转 | 钻机开启但无接触 | 默认关闭，可选极弱震动 |
| 钻机低能量/耗尽 | 首次进入阈值或耗尽 | 分别提示；无限能量不报警 |
| 喷气点火 | 实际推力从无到有 | 普通跳跃不触发 |
| 喷气推进 | 推力生效期间 | 低强度连续反馈，松开后淡出 |
| 喷气过热 | 首次进入过热锁定 | 双脉冲并压低背景震动 |
| 落地 | 连续移动中的空中→地面 | 按下降速度调整；忽略小落差和传送 |
| 炸弹装备/收起 | 成功切换装备状态 | 默认关闭 |
| 炸弹投出 | 成功生成、发射并记录炸弹 | 一次短震；失败不触发 |
| 炸弹附着 | 首次有效碰撞附着 | 按距离衰减，不重复附着提示 |
| 炸弹爆炸 | Explode | 距离平方衰减，遮挡降低强度 |
| LT 升级成功/失败 | 真实 Purchase 返回结果 | 成功双脉冲，失败短震；快速重复节流 |
| 初始装备拾取 | StartRoom 成功拾取 | 奖励双脉冲 |
| 藏品拾取 | 成功计入 Inventory | 奖励反馈，不对高亮触发 |
| 钻机/炸弹技能解锁 | 首次解锁 | 同次奖励反馈合并 |
| 回声敲击 | EmitEcho 通过冷却检查后 | 接触短震；不依赖音效覆盖回调 |
| 回声塌陷 | Collapse 首次执行 | 一次下沉冲击 |
| 回声落地 | EmitEcho 的落地事件 | 覆盖通用落地反馈 |
| 回声完成 | Complete 首次执行 | 完成反馈 |
| 思维/镜像交换 | 属性实际交换成功 | 双脉冲 |
| 交换拒绝 | 明确因规则/碰撞拒绝 | 默认关闭 |
| 解谜完成/奖励门 | 完成状态首次成立 | 奖励反馈；不对每个机关重复触发 |
| 办公室警报/失控 | 阶段警告与失控入口 | 默认关闭，间隔节流 |
| 办公室破门 | 玩家爆炸真正破坏出口 | 与同次爆炸合并 |
| 办公室封门/坍塌 | 对应演出入口 | 按距离衰减 |
| 标题贴墙 | 标题飞行动画到达终点 | 默认关闭 |
| 结尾钻进 | 钻进阶段每帧刷新短租期 | 低强度持续反馈；舒适模式减弱 |
| 结尾破岩 | FinaleDrillHit 有效命中 | 节流短震，舒适模式减弱 |

脚步、金币逐笔增加、挥空、普通菜单导航、光标/图鉴连续移动、字幕播放以及卡牌操作均不触发震动。

## 合并与生命周期

- 触发时使用当前本地玩家、角色、世界、区域和输入上下文；切换角色、场景、区域或界面时清理旧效果。
- 暂停、失焦、断连、切回键鼠、输入释放、关闭总开关或强度归零时立即停止；持续输出使用短时限动态句柄，失去刷新也会过期。
- 高频接触有冷却；同次敲击与破碎、落地与回声落地、爆炸与破门按组替换或合并。
- 不直接叠加强度：各效果取通道最大值。警告/大冲击将持续背景压到 20%。
- 连续钻机反馈必须保持实际接触；喷气必须保持实际推力。低能量/过热只在状态跨越时触发，不在冷却期间重复。
- 完成事件在关闭编辑界面的同一帧产生时，保留新结果反馈，清理旧界面的输出。
- 回声插件只暴露独立的语义事件，不依赖主游戏模块或音频是否可播放。
