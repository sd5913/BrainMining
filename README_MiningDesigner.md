# 矿业策划台

这是内置在 Unreal Editor 中的中文调参面板，直接编辑关卡里现有对象。没有另外维护一份容易与游戏脱节的配置，也不会替换现有关卡布局。

## 打开与基本操作

1. 打开需要编辑的关卡，停止 Play。
2. 顶部菜单 **Tools（工具）→ 矿业策划台**。面板可以独立放置，也可以拖动标签停靠在编辑器中。
3. 选择分类，再从对象下拉框选择生成器、房间、矿区或洞室。点击视口或 Outliner 中的控制对象，面板也会跟随切换。
4. 输入数值，或拖动原生数字滑条；悬停字段查看用途和生效时机。搜索框可以筛选当前对象、本分类的参数。
5. 地形参数修改后检查底部生成状态；必要时点击 **检查并重新生成**。角色参数重新 Play 即可验证。
6. 确认结果后点击 **保存当前关卡**。关闭工具不等于保存，保存预设也不等于保存关卡。

数值使用原生单位控件；例如 450 cm/s 可能显示为 4.5 m/s，这是同一个值。尺寸默认以厘米计。

空心矿区支持“串联矿区列表”和 **补齐相邻房间矿区**：摆放好主房间并编号后补齐连接，再分别编辑各矿区。已有路径不会被重置，列表引用不参与参数预设，详见 `README_HollowChain.md`。

若菜单暂时不可见，可在编辑器底部 Cmd 输入：

```text
py "E:/UE5/UEProjects/BrainMining/Scripts/open_mining_designer.py"
```

## 五个分类

| 分类 | 可调内容 | 生效方式 |
| --- | --- | --- |
| 角色与飞行 | 人物比例、移动和挖掘倍率、按住上升/松开下落、速度上限、推力和下落重力 | 下次 Play；不需要重新生成地形 |
| 挖掘手感 | 关卡覆盖开关、基础挖掘距离、半径、间隔、切入比例、向下偏移、安全重置深度 | 下次 Play |
| 场景与空间 | 主房间位置/尺寸/连接顺序、矿区和主通道、岩塞、洞室位置/尺寸、所属矿区、开放/隐藏入口、支路参数、材质 | 重新生成；启用自动生成时延迟更新 |
| 画面与调试 | 头灯、角色补光、开发者地图、剖切预览、基岩显示 | 剖面/基岩即时预览；照明/地图下次 Play |
| 高级与性能 | 每块预算、分块、保守简化、抵达房间判定、旧矿区冻结/回收 | 分块参数重新生成；推进参数下次 Play |

高级参数默认只读，每次切换分类后需要重新解锁。**每块三角形上限仍是 30000**，工具没有提高预算，也没有改变已有回收策略。

## 最常用的三个工作流

### 调飞行和挖掘手感

- 在“角色与飞行”调整上升速度、下落速度和推力。普通跳跃高度倍率仅在关闭飞行时影响普通跳跃。
- “挖掘手感”默认不覆盖角色蓝图：这是为了兼容旧关卡和已经调过的蓝图。
- 要从策划台调整挖掘，先打开 **启用关卡挖掘设置**；其余字段随后可编辑。
- 最终挖掘半径 = 基础半径 × 人物比例 × 挖掘半径倍率；距离和下偏也按对应倍率缩放。间隔不缩放。人物比例功能关闭时不乘这些倍率。
- 例如基础半径 120、人物比例 0.7、半径倍率 1，实际半径为 84，不会重复缩放。
- 安全重置深度为 0 时关闭坠落重置；正数会沿用原有地图安全深度保护，可能被提高，以免到下层房间时误重置。

### 移动洞室、改支路

- 选中 `CAVE_OPEN_MOVE_RESIZE` 或 `CAVE_HIDDEN_MOVE_RESIZE`，自动进入“场景与空间”。
- 修改位置、尺寸或缩放；也可以继续在视口拖动。位置表示地板中心，不是房间几何中心。
- 改“所属矿区”选择归属；移动洞室本身不会自动切换归属。洞室仍不是推进主房间。
- “隐藏入口”决定是否保留需要挖开的普通岩墙；“隐藏封口厚度”调整封口，不会换成不可挖基岩。
- **编辑路径点**会选择实际样条组件。随后在视口选中并拖动控制点。
- 首次手动编辑支路可使用 **直线支路控制点**，确认后生成直线控制点并打开手动模式。它会替换已有弯折，支持撤销。
- 不要编辑生成出来的 `GENERATED_*` / `PREVIEW_*` 对象。旋转、负缩放和超出几何约束的布局仍不受支持。

### 批量复用一组参数

- **复制参数 / 粘贴参数**：复制当前对象、当前分类的参数，可用于同类型对象。
- 输入名字点击 **保存预设**；选择同类型、同分类的预设，再点 **应用预设**。
- 文件位于 `Config/MiningDesignerPresets/`，可以随项目一起备份或纳入版本管理。覆盖同名文件需要确认。
- **恢复本页默认**使用当前蓝图/类的默认值，不会重置整个关卡。
- 预设、粘贴和默认恢复均保留：对象位置、样条点、所属矿区、起止房间引用、房间顺序、布局标识、材质引用以及手动路径模式。
- 自动生成开关与新旧地形生成模式也不随预设复制，避免无意切换整张图的生成逻辑。
- 开关的“关闭”和数值 0 会明确保存并恢复，而不是被当成“忽略此项”。

## 保护与限制

- 原生数值编辑和参数应用支持 Ctrl+Z / Ctrl+Y，面板也提供撤销、重做按钮。一次预设应用是一个撤销步骤。
- 粘贴/导入先检查整个预设，再修改对象；类型不匹配、未知字段、重复子字段、非法数值、超限预算、过大的列表等会被拒绝，不会只改一半。
- 数值合法不代表几何一定合法。地形生成仍调用已有校验和失败回退；失败时保留上次成功地形，底部显示原因。失败参数仍留在控制对象上，方便修正或撤销。
- Play 期间面板禁止写入，后端也拒绝对编辑关卡和 PIE 临时对象应用预设。停止后恢复编辑；这是离线策划工具，不是游戏内实时调参器。
- 当前角色参数需要关卡中有唯一的生成器。多个生成器会显示警告；不会猜测应该使用哪一个。
- 此版本集中管理已接入的原型参数，不是任意蓝图变量的自动编辑器。后续新增玩法参数应注册到分类目录后再显示。
- 材质引用可在面板修改，但不进入数值预设。原有英文 Details 面板仍可使用，与策划台是同一份数据。
- 暂不提供从面板一键新建完整关卡、热更新游戏包、玩家存档编辑或实时显示挖掘后表面的小地图。

## 开发与验证

手工设计通道两侧、独立空洞与支线房间，使用工具菜单或策划台中的 **矿道钢笔编辑器**。示例地图为 `Lvl_MiningManual_Demo`，操作方法见 [手绘矿道说明](README_ManualMine.md)。此工具保存独立源控制点，不会用旧自动布局覆盖手绘轮廓。

- 编辑器模块：`Source/BrainMiningEditor/`，仅 Editor 目标加载；Shipping 不依赖 Slate 调参面板。
- 分类、中文标签与提示：`Private/MiningDesignerCatalog.cpp`。
- UI：`Private/SMiningDesignerPanel.cpp`。
- 安全预设与 Python 接口：`Public/MiningDesignerLibrary.h`、`Private/MiningDesignerLibrary.cpp`。
- 关卡挖掘设置：`Source/BrainMining/MiningDiggingSettings.*`，在人物缩放前应用一次。
- 原生自动化：`BrainMining.Designer.*`；可与已有 `BrainMining.*` 测试一起运行。
- 编辑器集成验证：`Scripts/verify_mining_designer.py`，应在包含唯一生成器、房间与洞室的测试关卡中、停止 Play 后运行。脚本恢复测试参数，不保存关卡。
- 运行时验证：`Scripts/verify_mining_designer_runtime.py`，需先在测试关卡打开挖掘覆盖并开始 Play。脚本只检查真实角色数值与编辑锁，不保存关卡。
- 验证报告位于 `Saved/Validation/mining_designer_*.json`。

注意 Python 的 `apply_preset` / `save_preset` / `load_preset` / `reset_section` 返回 `str or None`：成功通常是空字符串，失败为 `None`。判断 `result is not None`，不要使用 `bool(result)`。
