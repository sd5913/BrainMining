## 本轮接入范围

| 场景 | 触发和处理 | 资源数量 |
| --- | --- | ---: |
| 挥镐 | 实际挖掘尝试；空挥也播放；钻头模式不播放镐声 | 3 |
| 第一击 | 有效岩面接触，播放轻挖击 | 5 |
| 后续挖击 | 同一受损区域的后续阶段，增加碎屑层 | 5 |
| 完整破碎 | 最终阶段的地形修改真正提交后播放；提交排队时不提前播放；重置不播放 | 3 |
| 地面行走 | 矿区、办公室、博物馆内，根据实际地面位移累计触发；静止、飞行、传送和交互界面不累计 | 5 |
| 落地 | 从空中回到地面且此前下降速度足够大时触发 | 1 |
| 金币入账 | 钱包实际增加余额；120 ms 限流，避免碎晶同时入账叠音 | 1 |
| 升级面板 | 按住/松开 Tab 导致面板实际开关时播放 | 2 |
| 主流程升级 | Hall 的购买流程返回成功或失败时播放；按钮被禁用时没有购买请求，也不会播放失败音 | 2 |
| 探索音乐 | Hall 当前区域为 Mining 时淡入；离开矿区淡出停止，回到矿区从头播放 | 1 |
| 木地板脚步 | 已导入备用，本轮未自动分配给房间 | 5 |

共 33 个资源，28 个有运行时播放路径，5 个木地板变体保留用于下一轮选择。脚步暂未按物理材质识别；所有当前玩家动作音采用第一人称 2D 播放。音效最多同时播放 8 个，变体避免连续重复，并有 ±4% 音高变化。音乐使用独立组件，不计入音效并发限制。

音乐默认音量 0.16，音效总量 0.7，再乘以各类事件的相对音量。音乐已做 3 秒首尾交叠，音乐乐句衔接、音色适配和实际响度仍需听感验收。挥镐目前使用轻刀划动/衣物声作试听替代，并非竹镐专门录音。

连续主流程通过 `AMiningExhibitHall::AreaKind` 判断当前区域；无 Hall 时仅 `Lvl_ExternalMining_Demo` 采用矿区音乐。Journey/回声通道/巨人房和结局暂不加入本轮脚步与探索音乐，保留已有房间声音设计。

## 编译后试玩

1. 保存并关闭 UE 编辑器，释放内存至至少 6 GB 空闲。
2. 在项目根目录运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File Scripts/Build_Safe.ps1`。
3. 如需重复验证，构建成功后运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File Scripts/AudioPilot_Safe.ps1 -Mode Test`。仅加载 Entry 空地图及小型测试世界，测试资产、同步挖掘事件、异步提交与取消、音乐区域切换和清理，报告在 `Saved/Automation/AudioPilot`。本次构建与这 4 项测试已经完成。
4. 从项目已有 `Play_Main.cmd` 进入主流程。先听第一矿区的行走、连续三击、矿物入账，再按住/松开 Tab，购买升级，走进办公室检查音乐淡出。
5. 重点听：持续挖矿是否刺耳、轻重击是否分明、破碎是否与画面同步、金币是否过密、离开矿区后音乐是否停下、音乐循环处是否自然。

开发控制台可使用：

| 命令 | 用途 |
| --- | --- |
| `bm.Audio.MusicVolume 0.10` | 降低探索音乐 |
| `bm.Audio.SFXVolume 0.50` | 降低音效 |
| `bm.Audio.MusicVolume 0` | 只关本轮背景音乐 |
| `bm.Audio.Enabled 0` | 停止本轮新音效，音乐淡出；已触发的短音效自然结束 |
| `bm.Audio.Enabled 1` | 重新开启本轮音频 |

这些开关只控制本轮组件，不控制既有房间的声音；当前只在本次运行生效。

## 重新处理与导入

一般调音只需调整组件中的事件音量，无需重新下载。重新处理需要 Python、numpy、soundfile；本机 soundfile 位于 `Saved/AudioPilotTools`。准备脚本读取 `Saved/AudioPilotDownloads` 内的四个源压缩包和音乐 MP3，生成选中的源文件、WAV 和清单，不自动联网。原下载缓存不纳入版本控制。

运行 `Scripts/prepare_audio_pilot.py` 后，用 `Scripts/AudioPilot_Safe.ps1 -Mode Import` 重新导入。导入只保存 `/Game/Audio/Pilot` 中选中的 33 个资产，不保存关卡。若命令行因已有启动错误退出，检查日志中的完成标记和导入报告，不能仅根据退出码判断素材是否保存。

本轮不包含钻头持续声、炸弹、吸附、回声谜题、卡牌战斗、水位、电视逃离、博物馆专项交互和结局专属配乐。下一轮应在实际试听后逐项补充。
