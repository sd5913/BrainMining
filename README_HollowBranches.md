# 可编辑支路与洞室

在已有空心矿区上增加开放支路、隐藏支路和洞室。不是下一阶段的随机生成器；原有地图不替换。

## 打开与试玩

- 地图：`/Game/MiningPrototype/Maps/Lvl_MiningHollowBranches_Demo`。
- 地图从原空心矿区演示复制，包含一个开放洞室和一个隐藏洞室。直接 Play，操作沿用原型。
- 角色支持按住空格上升、松开下落。速度及推力在生成器的 Player Flight 中调整，见 [飞行操作与参数](README_PlayerFlight.md)。
- 洞室与支路从原有普通岩体里切出空腔，没有独立基岩套管。隐藏封口仍是同一可挖岩体，不是额外重叠的墙。
- 洞室不是推进房间。探索洞室不会冻结当前矿区；到达 B 主房间才冻结整段，包括两个洞室。
- 开发者地图默认俯视，青色为支路、蓝色为洞室、粉色为隐藏入口、紫色为主路岩塞。M 开关、Tab 放大、V 切换视图、Home 全图/跟随、L 标签。显示的是生成布局，不是挖掘后的实时表面；挖开后封口设计标记仍保留。
- 仍为白盒；旧打包程序没有更新。

## 最常用的编辑操作

现在可以使用 **Tools（工具）→ 矿业策划台 → 场景与空间** 集中编辑；视口拖动和原生 Details 仍然可用，见 [矿业策划台使用说明](README_MiningDesigner.md)。

在 Outliner 的 `HollowDemo/EDIT/Chambers` 中选中：

- `CAVE_OPEN_MOVE_RESIZE`：开放洞室。
- `CAVE_HIDDEN_MOVE_RESIZE`：隐藏洞室。

只编辑这些控制对象，不要改 `GENERATED_*` 或 `PREVIEW_*`。

| 想做什么 | 操作 |
| --- | --- |
| 移动洞室 | 用移动工具拖动洞室对象。对象原点是地板中心，连接端点自动跟随。 |
| 调整大小 | 修改 `Chamber Size` 的完整长宽高，或者使用正数缩放。支路半径独立设置，不随洞室缩放。 |
| 更改所属矿区 | 指定 `Region`；必须与生成器引用的矿区相同，并位于同一关卡。未指定不会参与生成。 |
| 改支路入口位置 | 修改 `Connection Position`，它是主通道长度比例，不是固定 X 坐标。 |
| 改支路粗细 | 修改 `Branch Radius`。 |
| 开放/隐藏互换 | 切换 `Hidden Entrance`。 |
| 改隐藏入口厚度 | 修改 `Entrance Thickness`。这是主路安全包络之外的最小岩层厚度；实际需要挖的距离还包括入口肩部岩层。 |
| 临时关闭洞室 | 关闭 `Enabled`，保留编辑数据，地形和地图标记同时更新。 |
| 增加洞室 | 从内容浏览器拖入 `BP_MiningHollowChamber`，指定 Region，设置位置、大小和入口比例；也可以复制现有洞室后移动。 |

默认支路直连：移动洞室即可，不必编辑路径。

要手调支路形状，点击 `Reset Branch Path`，它会建立三点路径并开启 `Manual Branch Path`。选中 `EditableBranchPath` 样条组件后拖动中间点；两端始终自动连接主路和洞室。可以增加中间点，但最多四个。关闭 `Manual Branch Path` 回到自动直连；再次重建会替换原来的手工弯折。

`Reset Branch Path` 明确重置手工弯折，支持撤销。隐藏支路的第一个中间点应放在封口之后，不要紧贴主路口。

编辑停止约 0.3 秒后自动重建。批量修改时，可以关闭生成器 `Auto Rebuild`，改完点击 `Rebuild Tunnels` 或洞室的 `Rebuild Region`。Ctrl+Z / Ctrl+Y 支持撤销重做。

## 编辑失败时

查看洞室的 `Chamber Status` 或生成器的 `Last Build Status`。错误中包含对象名称和原因。

生成采用先检查、临时构建、成功后替换：失败不会替换上次成功的岩体、碰撞、开发者地图快照，也不会提交新的路径端点。无效控制对象仍留在你拖动的位置，便于继续修改或撤销；看到旧地形不代表当前参数已经生效。

常见处理：

- 超出矿区：把洞室移回整体岩区内，缩小洞室，或扩大 REGION 的 `Region Width` / 上下岩层余量。
- 靠近主路岩塞：调整 `Connection Position`，不要让支路意外绕空岩塞。
- 隐藏入口太短：把洞室或第一个路径点往侧面移动，或减小封口厚度。
- 和其他支路/洞室相交：移动或缩小对象；本阶段不支持环路与洞室互连。
- 坡度过大：调整洞室地板高度或延长侧向距离。

## 本阶段边界

- 每个矿区最多八个启用洞室；洞室为轴对齐、平底盒状空腔，尚无椭球或不规则洞室。
- 洞室不支持旋转，支持正数缩放；每轴尺寸至少为支路直径加 40 cm，至多 2500 cm。
- 支路半径 150–500 cm，封口厚度 50–600 cm，2–6 个线性路径点，最大坡度 25 度，转角不超过 60 度。
- 支路总体朝 Y 正向或负向侧伸，各段至少向同一侧推进 100 cm；暂不支持任意折返、分叉和自交。
- 洞室及支路距离整体岩区边界至少留 100 cm 普通岩石。连接点避开主路岩塞，洞室不能直接与主路重叠。
- 相交检查使用保守包围盒，有时看似没碰到也会拒绝，目的是避免意外打通隐藏空间；这不禁止玩家在游戏中自行挖出捷径。
- 原型仍是两间主房间、一个推进段；本次没有实现多矿区推进或自动随机布置。
- 保留单块 30000 三角形、每段 128 块预算。不会为增加洞室自动提高预算。
- 洞室没有单独灯光资产，沿用玩家照明；后续可以独立放置场景灯和装饰。

## 验证与安全

安装脚本 `Scripts/setup_hollow_branches.py` 只创建新演示地图，目标存在时拒绝覆盖。

以下测试只针对未自行改造的演示地图，几何/编辑测试会恢复并保存演示状态。不要在个人关卡上直接运行：

```text
py E:/UE5/UEProjects/BrainMining/Scripts/verify_hollow_branches.py
py E:/UE5/UEProjects/BrainMining/Scripts/verify_hollow_branches_editor.py
py E:/UE5/UEProjects/BrainMining/Scripts/run_hollow_branches_runtime.py
```

依次运行，后一个需等前一个完成；运行前应退出 Play。原生测试：`BrainMining.HollowBranches.*`。结果输出至 `Saved/Validation/hollow_branches_*.json`。

本机最终验证：9 项原生测试全部通过；342 项几何/编辑参数检查、9 项自动编辑/撤销回退检查通过。真实角色通过正常移动、跳跃和 12 次有效挖掘，探索两个洞室、返回主路并到达 B，地图定位与重置通过；没有用传送、飞行、关闭碰撞或运行时重生成完成通行。演示初始 24 块、最大单块 158 三角形，本次实走最大单块 1560；这不是其他布局的帧率承诺。Editor Development 和 Game Shipping 编译通过，旧打包程序未更新。审计确认 10 个原有地图文件未改变，汇总见 `Saved/Validation/hollow_branches_summary.json`。
