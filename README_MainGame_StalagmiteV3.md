# MainGame 第三段石笋通路

关卡 `/Game/MainGame/Maps/Lvl_MainGame` 已追加第三段石笋挖掘区域。前两段保留，第二段出口之后新增独立的 18 米房间预留连接空腔。

新主路约 176.46 米，下降 55 米，4 条支路各约 17.47 米；平面蜿蜒方向、局部弯曲和宽度节奏与第二段有变化。常规宽度约 3.3–9.8 米，两处石笋集中区扩宽到约 12.2 米、高约 9.8 米。12 根石笋高约 1.2–2.8 米，分别分布在两处空腔的两侧，中央保留通行空间。

石笋通过从通路切割体底部扣除封闭锥形体来形成，是最终可挖岩层的一部分；根部深入原地面 0.8 米，尖端留有空腔。切割体仍是一个封闭连通实体，Euler 特征为 2；没有上一段贯通顶底岩柱产生的孔。源文件里的石笋参考体已裁剪到地面之上，用于预览，不导出到 UE。

切割体体积约 8805.73 立方米，16 个独立贴合堵塞块合计约 4188.94 立方米，占 47.57%，符合约 50% 的目标范围。主路末端留空至少 10 米，各支路至少 5 米；石笋集中区和房间预留连接区留空。

## 编辑位置

- `EDIT_MainGame_03_石笋通路矿区`：160 个可挖岩层分块、16 个引导可挖层（18 个分块），外层是 1.5 米不可挖基岩。
- `EDIT_MainGame_连接预留区_02_18m`：8 个可挖岩层分块和不可挖外壳，未放阻塞块。
- `RESERVE_未来房间中心_02_18m连接空腔_勿放阻塞层`：未来房间位置标记。

第二段出口为 `(21300,0,-4680)` cm，新主路入口为 `(23100,0,-4860)` cm，间隔 18 米。连接体先提供连续的地面、顶壁和通行空腔，中部约 12 米宽、8 米高；没有加入其它玩法房间。

新模型共用 UE 平移为 `(29600,0,-11360)` cm。新阻塞块跟随新矿区第一个切割体变换；辅助连接体参与第二段和第三段矿区的切割，并独立生成中间预留区。中间区只使用已经完整延伸到两段入口内部的连接体，避免与两段通路模型重复相减造成共面布尔失败。第二段原有阻塞对象保留，第一段和第一处连接预留区不改动。
