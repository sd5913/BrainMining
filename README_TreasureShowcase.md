# 连续地图：宝物挖掘展示

入口仍为 `/Game/Showcase/Maps/Lvl_ContinuousShowcase`，保留原有六区，追加第七个宝物展区。不是新的测试地图，也没有传送或子关卡流送。

## 怎么体验

从出生点沿主步道向南进入基础挖掘区，在西南侧开口沿支路继续向南，即到宝物场。北排为普通岩石，南排为紫色引导岩石展示样本；每排默认九个独立岩块，宝物完全埋在其中。

- 左键挖掘，瞄准露出的宝物。界面显示名称、金币价值与估算暴露百分比。
- 暴露度严格大于50%时矿物会脱离岩石，轻微弹出、翻滚并受重力落地。瞄准矿物按E领取，空中或落地后都可领取；恰好50%不可领取。
- 领取后模型消失，右上角展示金币增加，底部提示本次收益。每件只结算一次。
- 领取范围为镜头前方 400cm，岩石和其他遮挡会阻止领取，不允许隔墙收取。
- 步行去其他区域保留本次试玩的金币和已领取状态，原收集图鉴不受影响。
- F5 在宝物区重开本展区：重新生成相同种子的宝物并清空本展区金币，不重置其他玩法。
- R恢复岩石时将尚未领取的掉落矿物放回原埋藏位置；已领取宝物不会复活，金币不变。
- F2 隐藏路线提示时仍保留金币和宝物操作提示；其他玩法的模态界面中隐藏宝物 UI。

## 如何配置

在地图 Outliner 中选择 `07_Treasure_Config_EditDefinitions`，Details 的 Treasure 分类：

| 属性 | 含义 |
| --- | --- |
| Definitions | 九种宝物配置，可增加或删除 |
| Id / Name | 唯一标识与显示名，ID 为空或重复时拒绝生成 |
| Model / Scale / Color | 原创低多边形切面矿物模型、尺寸与本体颜色，可替换美术模型 |
| HintColor / BuriedHint | 岩石透光颜色与开关，独立于本体颜色；煤炭使用暖灰提示 |
| HintRadius / HintStrength | 光斑世界空间半径（cm）与强度；默认 120 / 0.8 |
| EmissiveStrength / Roughness / Metallic | 本体自发光、粗糙度和金属感 |
| SurfaceStyle | 0～8 对应九种矿物，启用母岩遮罩、孔雀石条带或青金石金色颗粒 |
| ValuesBySize | 从小到大的四档固定金币价值，必须为递增正整数 |
| SizeMultipliers | 四档尺寸相对 Scale 的倍率，默认 0.55 / 0.70 / 0.85 / 1.00，必须递增 |
| Regions | 允许生成的区域 ID 数组，空数组不会生成 |
| Weight | 相对权重，零权重不生成；先过滤区域与岩层，再抽取 |
| NormalLayer / GuideLayer | 是否允许普通层／引导层 |
| RegionId | 本展区的宝物区域标识，默认 TreasureShowcase |
| RandomSeed | 固定种子，包含 0 在内都可复现，不代表每局随机 |
| SlotsPerLayer | 每排数量，1～9；与类型抽取权重相互独立 |

九种矿物采用四档固定价值，详见 Docs/TreasureProgression.md；例如铜矿从小到大为 8 / 10 / 15 / 20，不再随机生成区间内的11金币铜矿。类型按权重抽取，类型内四档暂时等概率。已有地图加载时，将没有四档配置的内置矿物按其ID迁移；已有模型、材质、基准尺寸、区域和权重不变。演示默认类型等权，不代表正式经济平衡。

布局使用两排固定安全槽位，槽内位置有小幅种子随机偏移，类型和值按配置随机。不会保证每种宝物都出现。模型尺寸超出安全岩块、缺少可采样碰撞、没有符合区域／岩层／权重规则的类型时跳过，GenerationStatus 显示实际数量。替换模型需要可用于复杂射线的碰撞，推荐凸形／近凸形网格。

新模型使用保留 CPU 数据的 LOD0 三角形，按表面积加权采样 384 个外表面点，剔除晶簇相交内部表面。外部替换模型没有可用 CPU 数据时回退到 128 个方向射线采样。暴露度是这些表面点中不被岩石覆盖的比例，不是摄像机可见像素比例，也不是严格的表面积积分。支持合并多个覆盖岩块的遮挡；本展示每个宝物使用独立岩块。岩块挖掘计数变化时更新暴露度，领取前重新验证。

## 矿物外观与埋藏光效

九种模型分别采用煤块碎簇、母岩铜矿、叠片锡矿、母岩铁矿、短簇硫磺、条带孔雀石、金点青金石、长柱紫水晶和双尖钻石。均为项目原创程序化网格，不包含《深岩银河》的提取资产。顶点色控制切面明暗与母岩遮罩，保持不透明受光材质，不依赖透明折射。

宝物完全埋藏时，覆盖岩石的材质已经显示局部彩色光斑，保留石纹，不显示穿墙轮廓或宝物模型。这是可控的材质提示，不是物理光线穿透。挖掘后的新切面同样使用世界空间衰减；矿物脱落或领取后光斑约0.25秒淡出，R恢复岩石不会恢复已领取宝物的光斑。

露出后补充小范围无阴影点光；只在当前展区启用，最多保留玩家 800cm 内最近四件，完全埋藏与已领取时关闭。不修改原六区灯光或全局曝光。当前光斑针对一岩一宝配置；不支持同一岩块自动混合多个宝物光斑。

紫色引导岩石在此是展示用可挖样本，不接管正式主矿区的引导通道生成。当前不改四大矿区流程，不增加背包或磁盘存档；物理掉落已接入，主关卡共享金币消费见 Docs/TreasureProgression.md。

掉落使用随实际模型尺寸变化的独立简单碰撞体，保留原网格的精确瞄准碰撞。启用连续碰撞检测，撞到地面后自然停止，不阻挡玩家。若矿物周围没有足够的释放空间，会等继续挖掘后再脱落，仍按原暴露度允许领取。离开展区暂停掉落运动，返回继续；领取后立即停止物理运动并隐藏。
