# 本轮体验调整（2026-10-20）

基于 main `84839f5c`。保留关卡中已有的城市布景、镜头空间轨迹和细胞模型。

## 谢幕界面在哪里调整

在 Unreal 内容浏览器打开：

`Content / EndingEmergence / UI / WBP_EndingCredits`

双击后进入 **Designer（设计器）**：

- `QuoteChinese` / `QuoteEnglish`：中英文引言。
- `AuthorChinese` / `AuthorEnglish`：作者与年份。
- `Contributors`：制作人员，富文本中的 `<cn>` / `<en>` 分别使用中文与英文字体，同一行保持基线对齐。
- `Prompt`：收集界面和退出提示。
- 选中对应文本即可调整内容、字体、颜色、Canvas Slot 的位置和尺寸。`ResponsiveLayout` 按 1600 × 900 设计尺寸等比适配屏幕。
- 在 **Class Defaults（类默认值）→ Credits** 调整黑场淡入、文字淡入和提示延迟。
- **Credits → CRT** 中 `CRTStrength` 控制轻微扫描线强度（默认 0.055，设为 0 关闭）；`ScanlineSpacing` 控制间距。

运行时加载这个 Widget Blueprint；创建辅助函数发现资产已经存在时会直接返回，不覆盖同事在 Designer 中的修改。

## 本轮行为

1. 卧室门根据房间内外方向选择向外旋转。
2. 起身镜头对齐玩家实际相机位置与 FOV，最后用 0.45 秒混合交接；开场结束状态在交接完成后才释放。
3. 捡镐后，只有视线实际命中出口土层才触发 0.9 秒标题渐显。
4. 收集界面只绑定 C；I 正常进入按键状态，供 SKIP 使用。
5. 谢幕加入轻微 CRT 扫描线。
6. 进入文思房后同时持续按 S、K、I、P 三秒，缩小并传送到老鼠展厅内，面向最后的画；松开任一键重新计时，后续仍按 E 进入结尾。
7. 字幕音效总增益降低至 45%，可在 `Config/DefaultGame.ini` 的 `[/Script/BrainMining.SubtitleSettings]` 中调整 `VoiceVolume`。
8. 取消盲人落地后的玩法旁白；收集物字幕保留。
9. 办公室炸弹出现后显示“拾取炸弹”路径点；与卡牌电视机使用相同绘制函数，拾取后消失。
10. 瞄准卧室可查看物件时启用通用白色轮廓，移开视线后清除。
11. 初始镜头提高，朝书桌、电脑和植物方向取景。
12. 消除盲人入口地板与矿道的重叠，并将竖井后墙顶面降低 2cm，避免黑色墙顶与紫色地板共面闪烁。
13. 正常速度下城市马路镜头增加两秒；空间轨迹不变。
14. 使用新视频 `cd6b00ed91f71a1dae98f8c2d8de0f22_raw.mp4`，去掉前 2.5 秒天花板等待段，HDR 转 SDR，1080p60 H.264，无音轨。原始文件保存在 `SourceAssets/EndingEmergence/Video/EndingFinaleSource.mp4`。洞口在石头破裂前保持隐藏；解码预热不再 seek 清空缓存；穿出前即启动播放。
15. 谢幕布局改为上述可编辑 Widget Blueprint。
16. 用项目内思源黑体粗体真实字形采样 WOoOW 的细胞目标点，增加笔画厚度，保留小写 o 及其钻入通道。字体或排列需重新生成时运行 `Scripts/generate_ending_title_layout.py`（需要 Pillow），不重新生成结尾关卡。

验证截图与报告位于 `Saved/Validation/Feedback16`。本轮未重新打包或推送。

## Ctrl + F10 工具快捷指令

游戏中按住左或右 Ctrl，再按 F10：矿镐直接升至当前满级（4 级），立即获得钻机和炸弹使用权，不扣除矿物或金币。工具所有权记录在现有 GameInstance 钱包中，沿用关卡切换的技能状态。仍使用 V 切换钻机、G 切换炸弹。

指令也会正确解除初始房间仅属于镐子的教学锁，收起原来的镐子拾取物；喷气背包保持原本的拾取流程。重复执行不会继续叠加等级，单按 F10 不会触发。
