# 外部通路矿区生成器

独立入口：UE 顶部 **工具 → 外部通路矿区生成器**。不依赖矿业策划台、旧样条生成器或旧房间布局；后续删除旧策划台不影响本工具。

## 使用

1. 打开或新建自己的关卡，打开工具，点击 **新建矿区**。
2. 设置 **可挖岩层尺寸**（长、宽、高，cm）和 **基岩外壳厚度**。外壳向岩层外侧扩展。矿区中心就是 Actor 原点；可以移动、旋转整个矿区，Actor 缩放保持 1。
3. 将 Blender 制作的封闭通路/洞室体积导入为 Static Mesh。
4. 点击 **添加通路模型**，展开 **Blender 通路切割体** 数组，指定模型和 **矿区内变换**。位置相对矿区中心，单位 cm。模型原点影响放置；以 1 米参考物确认导入尺寸。允许正的非均匀模型缩放。
5. **显示切割体预览** 仅用于编辑器定位，预览没有碰撞，也不会进入游戏。需要查看切割后的洞穴时关闭预览。
6. 点击 **生成 / 重新生成矿区**，检查生成状态，保存关卡，然后 Play。

无切割体时生成实心矿区。多个封闭体积依次切割，主路和洞室可以重叠。入口出口必须穿透整个外壳并伸出外侧；只挖空内部不会自动打开外壳。出口外的房间或其它矿区由关卡另外布置。需要岩塞时使用下面的引导可挖层。

生成结果包含可挖岩层（GeneratedMiningRock）和独立不可挖外壳（DynamicMeshActor）。同一个切割体同时减去两层；玩家只会挖掘岩层，基岩保留实体碰撞。结果跟随矿区 Actor 移动、旋转。`R` 沿用现有挖掘重置，恢复的是已经切出初始通路的岩层。

当前演示关卡使用专用角色 `BP_ExternalMiningTestCharacter`，其 MiningComponent 的 `FallResetDistance` 设为 0。旧默认值 2000 cm 会在角色低于出生点 20 米时回传并重置岩层，正常下降通路也会触发；0 关闭这项高度保护，`R` 手动重置仍有效。新建深层通路关卡时也需检查所用角色的此设置。当前角色已在 PIE 中验证下降超过 30 米不会回传。

修改模型、参数或重新导入 FBX 后需手动重新生成。生成失败保留上一版岩层和外壳；报错时配置与结果可能暂时不一致。新建、生成和清除支持编辑器撤销/重做。不要直接编辑生成结果，重新生成会替换它们。

## 引导可挖层（阻塞块）

1. 将单独的阻塞 FBX 导入为多个 Static Mesh：关闭 **Combine Meshes**，启用 **Convert Scene Unit** 将米换为厘米，保留与通路相同的原点、轴向和导入比例，不要分别居中。精确布尔产生的微小面需要保留，关闭导入选项 **Remove Degenerates**；若浮点换算产生真正退化边，先修复模型并保持封闭。
2. 在内容浏览器选中所有阻塞模型，工具中点击 **批量添加所选阻塞模型**；也可用 **添加引导模型** 逐个指定。重复模型不会再次添加。
3. 默认启用 **跟随通路变换**，**对应切割体索引** 为 0，对应第一个通路。共用原点的模型保持 **模型附加变换** 默认值。需要独立布置时关闭跟随并设置 **共用引导层变换**；各模型还可单独偏移、旋转、缩放或禁用。
4. 点击 **生成 / 重新生成引导可挖层**，检查状态并保存关卡。此操作只生成阻塞块，可在已完成的矿区上使用。

每个启用的阻塞模型生成一个独立 `GeneratedMiningRock`，具有实体碰撞和现有可挖玩法，在 Outliner 的 `ExternalMining/Generated/Guides` 文件夹中显示。阻塞块跟随矿区移动、旋转。引导层材质可统一指定，未指定时使用模型首个材质，再回退到岩石材质。

**恢复引导层** 仅恢复这些阻塞块；游戏中的 `R` 和矿区的恢复操作也会恢复阻塞块。**清除引导可挖层** 保留主岩层、基岩和模型配置；**清除本矿区生成结果** 会同时清除岩层、基岩和引导层。生成、重新生成和清除支持撤销/重做；失败保留上一版结果，不留下部分新阻塞块。

每矿区最多配置 128 个阻塞模型，全部阻塞模型合计最多 500000 三角形，单模型最多 250000；沿用矿区的分块尺寸和每块三角形预算。修改通路切割体的变换后，需重新生成引导层使其重新对齐。

## 模型与预算

- 通路表示要删除的空气体积，须封闭、无自交、无零面积面；曲线转 Mesh 前启用 Fill Caps。
- 导入时的重合边接缝会以 0.001 cm 容差尝试焊接；真实缺口不会自动补面。反向封闭组件会统一方向。
- 在 Blender 中仅将重叠实体 Join 会留下内部面，应 Boolean Union 或作为不同切割体输入。
- 单个切割体最多 250000 三角形，全部切割体合计最多 500000，数组最多 32 项。支持已有的 164280 面平滑通路和 9528 面 Lowpoly 通路作为输入。
- 分块边长 400–3000 cm，每矿区最多 8192 块，每块挖掘三角形预算默认和上限均为 100000。已有矿区保存的预算值会保留，可在工具中手动提高。
- 约 147 × 141 × 98 米的通路，可采用约 154 × 148 × 106 米岩层、默认 16 米分块，共 700 块。入口出口仍需延伸出外壳。较多分块会增加生成和碰撞构建时间；运行时挖掘只更新被命中的块。
- 生成在编辑器执行，游戏使用关卡保存的几何，运行时不读取 FBX 源网格。
- 使用 Static Mesh 的 LOD0 源网格。UE 资源的 Build Scale 保持 1；尺寸调整使用导入尺寸或本工具的矿区内变换缩放。
- 本版未导入路线语义、小地图、事件点、自动布置房间或出生点；主场景需要在关卡中布置 PlayerStart 和玩法 GameMode。

演示：`/Game/ExternalMining/Maps/Lvl_ExternalMining_Demo`。使用 UE 基础立方体和球体作为通路输入示例，并非 Blender 美术。可替换为自己的导入模型。

`Scripts/setup_external_mining_demo.py` 仅创建演示关卡，目标存在则拒绝覆盖。`Scripts/verify_external_mining_reload.py` 验证另一个编辑器进程加载已保存结果后，无需重新生成即可碰撞、挖掘和重置。

`Scripts/run_external_mining_runtime.py` 在独立编辑器进程中验证真实角色行走、现有 `TryMine` 和 `R` 重置，完成后退出该测试进程；不要在日常工作的编辑器里运行。
