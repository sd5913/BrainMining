# 挖掘收集原型 V0.1

本版先验收“挖出实体 → 掉落 → 瞄准白边 → E 收集 → 图鉴旋转查看”的完整流程。完成后等待试玩反馈，再推进下一版。

## 试玩

双击工程根目录的 `Play_Collection_V01.cmd`。它使用本机 UE 编辑器运行独立游戏窗口，无需打开编辑器再找关卡。

也可以在 UE 中打开 `/Game/CollectionPrototype/Maps/Lvl_Collection_V01`，点击 Play。该地图单独指定 `MiningCollectionGameMode`。默认启动地图和所有原有地图不变。

| 操作 | 按键 |
| --- | --- |
| 移动、观察 | WASD、鼠标 |
| 挖掘 | 按住左键 |
| 上升、下落 | 按住空格上升，松开下落 |
| 收集 | 准星瞄准出现白边的物品，按 E |
| 图鉴 | Tab 打开；Tab / Esc / 返回按钮关闭 |
| 查看模型 | 模型区域按住左键拖动，滚轮缩放 |
| 复位模型 | 双击模型区域、F 或复位按钮 |
| 新一轮 | R：恢复土层并清空本轮收藏 |
| 退出独立试玩窗口 | Alt+F4 |

建议先收集左侧台座上的试管架，体验图鉴；再寻找四面土墙上的管道、蚂蚁、彩色液滴和高处鸟巢。鸟巢可以按住空格飞上去挖。四类收齐时显示完成提示。

## 本版规则与策划来源

来源：`收集玩法【P1】.xlsx` 的“收集玩法”工作表，B2、B6:B9 和 A13:B33。表格作为玩法规格读取，没有把其中内容当作操作工程或发布的授权。

- 已实现：马桶、电脑、化学试管架、肉鸽四个程序化 lowpoly 三维模型；四种线索；物理掉落、瞄准轮廓、交互收集、名称简介、可旋转缩放的模型展示。
- 表中没有指定随机权重、埋深和暴露阈值。V0.1 的暂定规则为：四类各埋藏一件，随机交换四个区域，并在区域内随机偏移；另加一件完全露出且静止的试管架供教学。总计 5 件、4 类。
- 暴露比例默认 65%。计算实际模型表面采样点中，处于挖掘后岩体网格外部的比例；仅有效网格变化后重算，不根据尝试挖掘次数伪造进度。
- 达到阈值后，仍需找到容纳碰撞盒的空气区域和连续空气路径，才启用物理。避免刚体嵌在岩石中被剧烈弹飞。因此部分角度可能还需多清理一点土层。
- 从土中释放的物品会受重力影响，静止教学物品无需掉落。准星射线有 400 cm 距离限制并受岩体遮挡。
- 图鉴只展示已收集模型。未发现条目保留对应线索。收集数量与种类分开计数。
- 图鉴打开时暂停单人世界、取消持续挖掘及上升输入，避免拖模型时误挖。关闭恢复游戏。
- 本版收藏只在本轮内有效，R、结束 Play 或退出后不保留。尚无跨局存档。

## 调参

停止 Play 后，选择关卡里的 `Collection rules - seed and exposure`：

- `Exposure Threshold`：暴露阈值，0.1–1.0，默认 0.65。
- `Random Seed`：0 为每轮随机；正整数为固定布局。用于复现试玩问题。

本版挖掘半径为 115 cm，方便清理小型藏品；只在该测试关卡的角色实例上配置，原 Demo 的参数不变。

## 复用与隔离

- 继承现有 `MiningPrototypeGameMode`，继续使用同一角色和控制器蓝图、Enhanced Input、MiningComponent、DiggableRock 和 MiningCharacterMovementComponent。
- 使用项目现有的准星射线 / E 交互习惯。现有房间交互与房间流程耦合，没有通用收集背包，因此新增独立收集管理 Actor。
- 新 Level、材质全部位于 `Content/CollectionPrototype`。模型在运行时生成，未修改旧关卡、旧材质或默认 GameMode 配置。
- 公共代码只增加 `MiningComponent.CancelMining()` 接口及 SlateCore 构建依赖。原有挖掘算法未修改。

## 验证

- `BrainMiningEditor Win64 Development` 编译通过。
- 原生测试 `BrainMining.Collection` 两项及原有 `BrainMining.Flight` 三项通过。曝光测试使用临时世界，报告带临时世界销毁上下文警告，无失败项。
- `Scripts/verify_collection_v1.py`：34 项 PIE 集成检查通过，覆盖四类真实挖掘、物理释放、遮挡、收集去重、图鉴、固定/随机种子和旧 MiningLab 的挖掘/重置。
- 集成测试在每件物品前移动角色到测试起点，随后调用原有角色挖掘组件并使用真实瞄准射线；不代表完整人工通关或帧率测试。
- 报告：`Saved/Validation/collection_v01_runtime.json`、`Saved/Validation/CollectionAutomation/index.json`。
- 运行编辑器命令行验证时，仅在命令参数中禁用 `AllToolsets,ModelContextProtocol`，避开工程已有的 GameFeatureData 扫描报错。项目插件配置未更改。
