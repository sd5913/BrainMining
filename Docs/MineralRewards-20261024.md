## 获取与保存

- 数量只在 `AMiningTreasureField::CollectTarget` 成功收入矿石后累计。露出矿石、GM 加材料、升级消耗都不改变累计进度。奖励不消耗矿石。
- 所有未解锁藏品卡片都允许选中、翻页并显示选中高亮；详情显示“尚未解锁”，隐藏模型与已解锁介绍。最后一页这四件还显示收集门槛和当前数量。
- 达到门槛自动解锁，每种只授予一次。ID 0–11 保持不变；原有藏品仍可在保留图鉴的新周目中正常生成和收集。
- 存档版本升至 5，保存累计数量。版本 1–4 根据已经收集的矿石 placement ID 恢复真实数量，不用剩余背包余额推算。旧存档新满足的奖励会补发。
- 继续游戏恢复已解锁奖励且不重播动画。开始游戏清空本轮矿石累计数量；选择保留只保留图鉴，选择清除同时清空图鉴。

## 收集演出

所有正常藏品拾取与矿石奖励均进入同一动画队列：约 1.15 秒中央透明模型展示，约 0.8 秒弧线缩小飞向左侧 `[C]查看藏品`，到达后入口缩放、金色闪动。奖励在动画开始前写入库存，暂停／查看图鉴会暂停动画，不影响物品归属。

使用独立 512×384 的透明离屏纹理；仅展示阶段按 24 Hz 更新，飞行阶段复用冻结纹理，空闲不捕获。模型只在创建时生成，动效更新组件变换，不逐帧重建网格。孔雀石为静态展示，其他新藏品在检视时按 30 Hz 更新动效。

四个新提示音由 `Scripts/create_mineral_reward_audio.py` 合成，源 WAV 与导入脚本均在仓库中；无第三方授权依赖。

## GM 解锁

Windows 成品包进入游戏后按 `Ctrl + F10`，在「GM · 矿石藏品」中选择单件解锁或「一键解锁四件矿石藏品」。成功后自动关闭面板并播放收集动画。已解锁的不重复授予，不改变矿石余额或真实收集进度，已有藏品保持不变，正常写入存档。

GM 面板顶部常驻三段通路、电脑房、盲人通道／卡牌房、博物馆的六个主流程入口。当前为独立测试地图时，选择入口会返回 MainGame、恢复可继续的存档，再跳转；没有可继续存档时以保留图鉴的新游戏进入。主流程内直接跳转保留当前房间状态。移除了「卡牌房 · 独立测试」和「旧主流程 · FullJourney」两个入口。

所有 GM 操作只通过窗口按钮执行。移除 UI 隐藏快捷键、满级装备隐藏快捷路径、F6 返回起点、F7 跳房间和旧 F4 菜单快捷键；返回起点和跳房间改为 GM 按钮。没有藏品解锁控制台指令。`Ctrl + F10` 仅打开 GM 窗口，隐藏 UI 时仍可打开 GM 并点击「恢复全部 UI」。

`Scripts/verify_mineral_gm.py` 在独立存档中验证四个真实按钮、重复授予、重启读档、通路跳转与快捷键移除。用户已取消动画录制，仅验证游戏中实际动画状态。
