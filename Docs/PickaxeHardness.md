# 镐子养成与岩层硬度

在 Unreal 顶部「工具 → 矿镐养成数值」打开现有调参面板，展开「等级 0～4」中的等级 0：

- 每击基础挖掘深度（厘米）：Depth，默认 208 cm。
- 挖掘范围边长（厘米）：Width，默认 320 cm。它是切割洞口的基础边长，不是射线距离；对应基础半径 160 cm。
- 挥镐间隔（秒）：Interval，默认 0.3 秒。

等级 1～4 自动继承等级 0 的基础值，破坏等级分别为 1～4。等级 2 起范围累计乘 1.25，等级 3 起间隔累计乘 0.75；等级 4 沿用这些累计增益，不再缩减固定击数。面板「升级倍率」可调整这两个倍率。基础值修改后各等级自动派生，避免重复配置。价格及商店说明仍可逐级设置。点「保存并应用」后，新游戏与打包版本均读取相同配置；面板也支持在 PIE 中试用草稿与恢复已购等级。

文本配置位于 `Config/DefaultGame.ini` 的 `[/Script/BrainMining.MiningPickaxeSettings]`。等级 0 的 `Depth`、`Width`、`Interval` 是基础值，`RangeUpgradeMultiplier`、`IntervalUpgradeMultiplier` 是升级倍率；其余等级的尺寸以基础值派生为准。

每击实际深度 = 基础深度 × 人物挖掘尺寸倍率 × 等级差深度倍率。等级差 = 镐子破坏等级 − 命中岩层硬度；差值 -4 及以下不能破坏，-3/-2/-1/0/1/2/3/4 及以上依次为 0.25/0.5/0.75/1/1.5/2/2.5/3。倍率影响沿命中法线的深度，不改变挥镐间隔或洞口范围。碰撞和实体布尔切割使用同一深度。

MainGame 四区的普通层硬度分别为 0/1/2/3，堵塞层为 1/2/3/4。原 32 处引导层、房间接口与起始连接土层一起应用对应区域的硬度。不可挖外壳继续不可挖。房间自身玩法和炸弹、钻机的破坏规则保留。

配置场景硬度时，选中「外部通路矿区」Actor，在 Details 修改「普通可挖层硬度」和「堵塞层硬度」。已有生成结果会直接同步，无需重新生成地形；之后重新生成也会继承这两个属性。独立可挖 Actor（包括六处房间接口）可在 Details 的 `Mining → Hardness → 岩层硬度等级` 单独调整。保存 MainGame 后生效。

底层实现：`MiningPickaxeSettings` 解析养成与等级差倍率；`MiningComponent` 将命中岩层硬度应用到实际镐子切割；`MiningExternalRegion` 同步生成物的硬度。旧版逐击阶段 API 保留用于专门设置的旧流程；当前养成配置使用每击独立挖掘，不再固定三击或两击打通任意厚度。
