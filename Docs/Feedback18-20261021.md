# 打包试玩反馈调整（2026-10-21）

| 项目 | 修改后的行为 |
| --- | --- |
| 满级矿镐 | 4 级使用现有 `SM_Pickaxe_max` 钻石镐，切换网格时清除旧等级的材质覆盖。 |
| Ctrl + F10 | GM 菜单增加「升级矿镐一级」「解锁炸弹」「解锁钻机」。升级免费、最高 4 级；炸弹和钻机同时补满使用次数/能量。 |
| 谢幕藏品 | 沿用主流程藏品的生成代码；天堂马桶的网格、材质和缩放通过 GameInstance 保留，切换到结尾后仍使用游玩时的展示资源。 |
| 机器人断眉 | 第三轮火烧命中、播放「啊啊啊！我的眉毛！」时，只从原眉毛中间去掉约 8% 的一小截。保留原顶点、纹路和朝向，不移动、缩放或额外旋转两端。后续表情和下一轮保持断眉，重新开始对战时恢复。 |
| 卡牌结束字幕 | 「这种卡牌玩法会不会太常见了呢？」 |
| 上涌水字幕 | 「水？上涌的水…不断地跳」 |
| 彩带字幕顺序 | 成功拾取后，依次播放「好漂亮的彩带」「继续往前走走」，共用现有字幕队列和行间隔。 |
| 天堂区域音效 | 使用用户提供的 `dragon-studio-angel-choir-463220.mp3`。进入区域播放一次，停留不重复，离开后再次进入重新播放；边缘有 100 cm 防抖范围。音效不循环，并发上限 1。 |
| 玩家脚印 | 左右镜像的鞋底形状，包含前掌、足弓、后跟间隙及浅鞋纹；鞋尖沿行走方向。保留原亮度、停留和渐隐时间。 |
| 博物馆交互 | 「进入画中的圆圈」 |
| 结尾音乐 | 从静音开始，约 0.35 秒后逐渐进入，约 4.35 秒达到原目标音量；首次加载卡顿不会直接跳过渐入。 |
| 结尾钻机 | 钻机前进段持续显示底部居中的「W 加速前进」，沿用博物馆 18 号白字、黑色阴影及 40 px 底边距。 |

检查中同时修正了可乐细节模型超出旧拾取盒的问题；计算器测试改为验证已有的弹出收集行为仍保留朝向。

## 资源与复验

已通过 Windows Editor 编译、16 项 Native 回归、音乐连续性测试，以及主流程/谢幕、卡牌、结尾三组实际画面检查。断眉二次修订后已重新编译并复测卡牌全过程；原眉毛资源校验值未改变。

- 资源更新脚本：`Scripts/apply_playtest18_assets.py`。只保存上述字幕、脚印材质及音效，原资产备份在 `Saved/Validation/Playtest18/Before/`。
- 音效资产：`/Game/Audio/Rooms/S_HeavenAngelChoir`。保留原 MP3；运行音频为完整 18.312 秒单声道 WAV，接入 Effects 音量。
- 断眉资产：`/Game/Rooms/CardDuel/Robot/SM_Robot_BrowL_Singed`，由 `Scripts/create_singed_robot_brow.py` 从原眉毛裁去中间一小截；不改原资源。
- `Scripts/Run_Playtest18Checks.ps1 -Mode Native`：卡牌规则、断眉保持、收集、升级、音效重复进出、GM 房间跳转回归。
- `Scripts/Run_Playtest18Checks.ps1 -Mode Music`：结尾音乐渐入、循环、镜头切换、谢幕和重开连续性。
- `Scripts/Run_Playtest18Checks.ps1 -Mode Visual`：GM 菜单、钻石镐、真实行走脚印、彩带字幕顺序、实际关卡切换后的谢幕藏品对比。报告及截图在 `Saved/Validation/Playtest18/Visual/`。
- `Scripts/Run_PlaytestPolish.ps1 -Mode Cards` / `-Mode Ending`：卡牌断眉与结尾底部 W 提示的实际画面。

`Scripts/package_main_game.ps1` 已增加新音效和满级镐的容器资产检查。旧打包程序不会自动获得源码或资源修改，需要重新打包。
