# 办公室离开流程

独立关卡：`/Game/PopupClose/Maps/Lvl_PopupClose`。

保持原来的办公处理与金币奖励。办公 65 秒后开始喷弹窗和纸，喷出量逐渐增加；喷发 32 秒后停止，并从中央电脑弹出项目已有的 `SM_Bomb` 炸弹模型。靠近并瞄准炸弹按 E，解锁角色已有的炸弹技能并补充初始库存；G 装备、鼠标左键投掷，继续使用原有倒计时、补充、升级和爆炸系统。未拾取前禁止装备炸弹和购买炸弹升级。

对面出口的门只会被范围内、没有遮挡的真实玩家炸弹爆炸破坏。炸开门不会立即炸毁房间。玩家完整穿过出口后，回路立即封闭，四台工作设备与八台其它电脑开始喷炸弹，默认 5 秒后爆炸并形成废墟。堵路碰撞覆盖整个房间高度，飞行也不能绕过。演出炸弹使用最多 384 个模型实例，爆炸不执行挖矿或发金币，也不对门外玩家施加冲击。

在 `PopupCloseStage` 的 `PopupClose | Exit` 中可修改 `EruptionBeforeBombSeconds` 和 `EvacuationBombSeconds`。炸弹解锁状态保存在现有 GameInstance 账户中，跨区域和角色重建保留；与现有金币/升级一样，目前不是跨启动存档。

拼接到流程时保留房间本地 +X 的出口和门廊。`GetCompletedSessions()` 在门被炸开后返回 1，供连续流程解除后方进度门；`OnOfficeEscaped` 在玩家穿门、回路封闭时触发，`OnOfficeDestroyed` 在废墟形成时触发。`IsOfficeEscaped()`、`IsOfficeDestroyed()` 和 `GetExitStatus()` 可用于其它程序查询。房间使用世界计时器完成演出，离开时关闭房间 Actor Tick 不会打断坍塌；需保留该 Actor 所在关卡直到销毁事件完成，再卸载场景。

现有 `PopupClose.Reset` 会恢复房间、出口门和办公轮次，清除炸弹及废墟演出；已获得的金币和炸弹技能保留。连续流程禁止回访已经撤离的办公室，避免传送到废墟碰撞体中。

验证：`BrainMining.Office.ExitFlow` 使用真实 E/G/鼠标输入、实际技能炸弹与爆炸计时，检查远距拒绝、重复拾取、远处爆炸不破门、炸门通行、回路封闭、停用 Actor Tick 后坍塌、飞行封堵以及重置保留技能。
