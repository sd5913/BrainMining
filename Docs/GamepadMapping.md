# 手柄输入与验收

Xbox 命名；PlayStation 按物理位置对应底部确认、右侧返回、左侧交互、顶部工具。卡牌房支持手柄完成入座、选牌、出牌和领奖，保留鼠标与空格操作。

## 默认布局

| 输入 | 探索 | 场景覆盖 |
|---|---|---|
| 左摇杆 | 移动 | 菜单、图鉴方向导航；牌局左右选牌 |
| 右摇杆 | 视角 | 电脑/编辑/菜单光标；图鉴旋转 |
| A | 跳跃，按住喷气 | 电脑点击；编辑交换；菜单确认；牌局选中/取消当前牌，胜利后领奖 |
| LT | 直接升级一级镐子 | 电脑光标精调；图鉴缩小 |
| RT | 挖矿、钻机、装备炸弹后的投掷、回声敲击 | 电脑和界面点击；编辑拖拽；图鉴放大 |
| B | 创造飞行下降 | 返回最上层界面；电脑退出；牌局清空已选牌 |
| X | 目标交互（含初始房间开门） | 普通/镜像思维交互；牌局入座、出牌、领奖 |
| Y | 钻机切换 | 普通/镜像思维编辑；图鉴复位；牌局全选/清空 |
| LB | 预留 | 普通思维关闭左侧，镜像清空；图鉴前一项；牌局前一张 |
| RB | 装备/收起炸弹 | 普通思维关闭右侧，镜像交换；图鉴后一项；牌局后一张 |
| View | 无动作 | 不再打开地图 |
| Menu | 暂停 | 关闭后恢复原界面 |
| 十字键上 | 图鉴 | 界面方向导航 |
| 十字键右 | 无探索动作 | 界面方向导航 |
| 十字键下 | 长按 0.8 秒请求当前场景重置 | 保留卡牌房间、结尾及矿场自身的重置限制 |

## 卡牌房间

- 走近牌桌按 X 入座。匹配、对手入场和出牌动画期间，仅保留 Menu 暂停，不会误触挖矿、飞行、炸弹或升级。
- 选牌时用十字键左右、左摇杆左右或 LB/RB 移动焦点；A 切换当前牌的选择状态，Y 全选/清空，B 清空选择但不离座、不重置牌局。
- 焦点牌用青色边框、上移并置顶显示，已选牌保留金色边框与抬起状态，17 张重叠牌也能逐张查看和操作。换回合时焦点回到第一张。
- X 出牌遵守现有规则：必须选齐本回合的牌；第 4 回合未选齐时，首次 X 先全选，第二次 X 出牌，与原空格快捷操作一致。提示同步显示全选或出牌及已选数量。
- 胜利后按 X 或 A 领取钻机，恢复位置、碰撞、移动和视角，回到探索输入。
- Menu 暂停后 B 返回牌局，保留选择和焦点。鼠标与键盘仍可使用，并与手柄选择共享状态。
- 牌局提示移至顶部以避开手牌，保持现有弹幕字体、SVG 图标和字号。中央出牌提示在手柄模式显示 X，键鼠模式显示空格。
- 验证：完整 Editor 编译通过。专项报告 Saved/Validation/Gamepad/20261019-232513/index.json 为 5 项通过、0 警告、0 失败；综合报告 Saved/Validation/Gamepad/20261019-233032/index.json 为 26 项通过、0 失败，其中 2 项仅有外部联网探测超时警告。覆盖真实 Slate 手柄事件、四回合、暂停恢复、17 张牌、领奖恢复、主关卡卡牌与电视逃生衔接、初始门及飞行/震动回归。使用 NullRHI 验证，实体 Xbox 和 GPU 画面仍需实机验收。

## 升级与输入边界

- LT 每次按下尝试购买一级镐子，使用现有进度与材料/金币规则；不打开升级面板、不暂停、不显示鼠标，也不锁定移动或挖矿。
- 长按、重复按键事件与扳机模拟量不会连续购买；松开再按才能再次购买。按住 LT 进入或退出暂停不会补触发升级。
- 升级成功或资源不足/已满级时，在底部显示 2.5 秒反馈并播放既有购买反馈音。
- 开场装备未解锁、输入锁定、暂停、遭遇禁用及其他界面不允许升级。LT 在电脑与图鉴内继续负责精调和缩小；A 保留跳跃与按住飞行。
- 手柄地图入口和提示已移除；原有键鼠地图系统保留。
- 设备事件由本地玩家子系统先行处理，避免默认 IMC 再次处理同一手柄动作。
- 场景内直接调用语义动作，不模拟键盘输入。RT 投弹后不会接着挖矿。
- 切换上下文、Pawn、区域、失焦或断连时释放挖矿、飞行、拖拽及确认键。
- 电脑点击使用当前光标命中的 Widget Interaction，不调用移动端的自动回复。
- 开始游戏沿用标题飞向墙面的开场流程，演出结束后恢复角色、视角与碰撞。

## 提示样式

- 保留底部位置与 14 号游戏字体大小，使用现有弹幕的 Source Han Sans CN Bold 字体、白字阴影及轻微红青错色和漂浮。
- 移除整条深色底框；横向提示在较窄视口内仅缩小，不放大。
- 使用 Content/UI/Gamepad 下的 12 张 SVG 按键图标：彩色面键、扳机、肩键、右摇杆、十字键及菜单键。
- SVG 作为 NonUFS 运行时依赖随打包产物分发。
- 根据电脑、图鉴、菜单、思维编辑、牌局和探索上下文切换提示；键鼠输入切回原有提示。牌局使用顶部提示以避开手牌，其余场景使用底部提示。

## 配置

在 DefaultGame.ini 的 [/Script/BrainMining.MiningGamepadSubsystem] 节中可配置：

- StickDeadZone：默认 0.18，径向死区。
- LookDegreesPerSecond：默认 135。
- CursorPixelsPerSecond：默认 900，电脑 LT 精调至四分之一速度。
- bInvertLookY：默认 false。
- ResetHoldSeconds：默认 0.8，最小有效时长 0.4 秒。

bLeftTriggerFlight 已移除；LT 不再用于飞行。
