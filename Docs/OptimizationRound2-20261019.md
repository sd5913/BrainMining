# 2026-10-19 第二轮场景与结局优化

本轮对应九项试玩反馈，正式入口仍为 MainGame。

| 反馈 | 修改 |
| --- | --- |
| 左侧书堆与尺子缺碰撞 | 对 P2 左侧上桌区域的 32 个可见实体补齐碰撞；导入模型使用独立 `_Walkable` 网格的精确三角碰撞，保留原素材和隐藏的路线支撑。MainGame 引用同一 P2 子关卡。 |
| 地面机器人坐姿与朝向 | 身体贴地，向前伸出的双脚落到地面；朝向房间入口玩家。 |
| 对战机器人脚悬空折叠 | 移除旧书堆垫高留下的坐标，骨盆落到椅面前沿；双腿向下旋转 65°，只有击飞时恢复翻滚动作。比例调整为 10、入座仰角为 7°，脸部完整露在桌面上方。 |
| 细胞房玩家模型可见 | 进入或重置结局时隐藏身体与第一人称手臂，保留子节点上的摄像机和工具。 |
| 彩带迎接舞台 | 两侧加正面共三个筒，前 0.18 秒集中喷发，随后循环喷射；收集物由中间筒立即发射，0.9 秒落地。筒口与粒子起点共用坐标。 |
| 炸弹尺寸与出口门 | 投掷模型放大至 1.4 倍；电脑奖励由 3.2 倍缩至 2.2 倍。出口碰撞门在运行时恢复可见，并附加原办公室门模型，爆破与重置同步显隐。 |
| 桌面台词 | 改为“唉算了，涌现不出来了，我们去吃饭吧。”；触发点从桌面镜头 4.05 秒延后到 4.85 秒。 |
| 星云时间 | 星云前的地球镜头由 10 秒延长到 11 秒；后续连续宇宙轨道保持原有时长与接缝。 |
| 血管油画残留 | 油画仅加入细胞玩家镜头，电影镜头始终移除；进入血管的同一帧、切换视点前清除玩家油画。 |

## 验证结果

- Editor 编译成功。Office、Card、Ending、Scale、Finale 五组自动化均通过，零测试错误；Ending 仅有一条外部 HTTP 连通性请求超时警告。
- 已保存的 P2 关卡在 PIE 中检测 32 个可见实体，获得 224 次有效碰撞命中；检查地面机器人朝向、双脚贴地，以及对战骨盆与椅面、双腿下垂关系。四张坐姿和楼梯截图保存在本轮报告目录。
- `verify_optimization_office.py` 在 MainGame 的真实流送办公室中确认出口碰撞门和门模型都可见，截图为 `OfficeVisual/office-first-exit.png`。预览退出曾出现编辑器关闭异常，改为结束 PIE 并卸载到 Entry 后退出，最后复跑正常返回。
- 电视测试使用真实钻头与玩家胶囊扫掠，通过 146 个路径点，15 块连续通道均被实际挖开；三筒喷发、开幕 1.2 秒内彩带已落地、瞄准后按 E 收集且库存恰好加一均通过。
- 结尾实际画面已检查新台词；细胞、血管、神经、重置流程与宇宙镜头时长均通过对应回归。
- 打包脚本会检查 IoStore 内的 31 项必要资源，包括出口门、机器人双脚和本轮 10 个独立碰撞网格。正式包使用 Win64 Shipping、MainGame 默认入口并包含结局地图。

验证包含自动化交互和截图检查，不等同于完整人工通关。Windows 打包、容器清单和交付压缩包的校验结果保存在 `Saved/Validation/MainGamePackage` 与 `Saved/Validation/OptimizationRound2`。
