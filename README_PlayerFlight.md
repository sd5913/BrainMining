# 按住上升、松开下落

当前矿区场景默认启用。角色继续使用正常胶囊碰撞和落地检测，不是编辑器自由相机，也不允许穿墙。

## 操作

- 按住空格：持续上升；下落时再次按住，会先减速再上升。
- 松开空格：立即取消向上的惯性，随后由重力加速下落，不会悬停。
- WASD：地面正常行走，空中控制前后左右；视角抬高不会把 W 变成上升。
- 鼠标和左键：照常瞄准、挖掘；需要挖穿普通岩石才能通过，基岩仍不可破坏。
- R：重置开挖和进度，同时清除飞行输入及速度。若重置时仍按着空格，需要松开再按一次。
- 松手落地后正常站立，再按空格即可重新起飞。碰到天花板会被挡住。

## 在哪里调

推荐使用 **Tools（工具）→ 矿业策划台 → 角色与飞行**，中文界面支持预设和撤销。操作说明见 [矿业策划台](README_MiningDesigner.md)。原有 Details 调参方式仍保留。

停止 Play，选中当前关卡的 `MiningTunnelGenerator`（场景生成器），展开 Details 的 **Player Flight**。
修改后重新 Play 即可，不需要重新生成地形。这里的值不会增加地形网格或三角形预算。

| 属性 | 默认值（玩家缩放前） | 用途 |
|---|---:|---|
| Enable Hold-to-Fly | 开 | 关闭恢复原本的空格跳跃 |
| Ascent Speed | 450 cm/s | 上升速度上限 |
| Max Fall Speed | 650 cm/s | 下落速度上限，调低更容易控制 |
| Air Move Speed | 500 cm/s | 上升及下落时的水平速度，不改变地面行走速度 |
| Lift Acceleration | 1800 cm/s² | 净向上加速度，调高更快刹住下落、转为上升 |
| Fall Gravity Multiplier | 1 | 松手后的下落加速度倍率，调高落得更快 |

目前 Player Scale = 0.7 时，默认上升上限为 **315 cm/s**，下落上限为 **455 cm/s**，空中水平上限为 **350 cm/s**（Movement Speed Multiplier = 1 时）。
水平速度也跟随 Movement Speed Multiplier；竖直速度、推力跟随 Player Scale，但不跟随该水平速度倍率。
重力保留已有的玩家缩放计算，再乘 Fall Gravity Multiplier。Jump Height Multiplier 只用于关闭飞行后的普通跳跃。

## 兼容与边界

- 房间触发、同矿区洞室、开发者地图、照明及挖掘逻辑不变。开发 HUD 显示 LIFT / FALL / GROUND 和竖直速度。
- 地图上只有一个生成器时，它的 Player Flight 是参数来源。不管 Player Scale 是否开启，都可以单独开关飞行。
- 没有生成器的旧模板关卡默认仍然跳跃；可以在角色蓝图 Character Movement 组件的 Player Flight 中手动开启。
- 多个生成器时不任意选择，使用角色蓝图的设置并输出警告。
- 输入 Completed / Canceled、解除控制、R 重置均清除上升状态。移动被禁用、游泳等模式不会被飞行强制覆盖。
- 本版面向当前单机原型。没有实现网络预测或多人推力输入复制，也没有额外制作喷气背包模型、动画或特效。
- 编辑器工程与旧打包目录不同；旧打包游戏需要重新打包才能获得本功能。

## 验证

- 原生测试：`BrainMining.Flight` 覆盖推力、松手取消上升惯性、空中再次起飞、速度上限、0.25 / 0.7 / 1 / 2 玩家缩放、15 / 30 / 60 / 120 Hz 以及非法参数保护。
- `Scripts/verify_player_flight.py`：在已启动 PIE 的当前支路演示地图运行，使用真实 Enhanced Input action，检查升降、地板/墙/天花板碰撞、空中挖掘、不可挖基岩、地图、下一房间推进、重置和关闭飞行后的普通跳跃。
- 运行期脚本仅在 PIE 世界中重置、测试；独立用例之间会移动角色到测试起点，不绕过测试过程中的移动与碰撞，不保存或加载编辑器地图。运行前请结束自己的试玩，因为它会重置本次 PIE 的挖掘进度。
- 结果：`Saved/Validation/player_flight_runtime.json`。本次 24 项运行期检查通过，场景没有运行期重新生成，三角形预算仍为每块 30000。
