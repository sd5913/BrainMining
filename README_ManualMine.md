# 手绘矿道与空间编辑器

这一版以手工设计为主，不随机重排矿道。通道两侧分别保存控制点和贝塞尔手柄；空洞、支线房间、支线通道都是独立对象。重新构建只更新地形，不替换已画好的中段轮廓。

## 打开与体验

1. 编译 `BrainMiningEditor Win64 Development`，打开工程。
2. 打开 `/Game/MiningPrototype/Maps/Lvl_MiningManual_Demo`。
3. 选择 **工具 → 矿道钢笔编辑器**；原来的“矿业策划台”也有入口。
4. 左侧为 X/Z 横截面，右侧为当前对象的属性。顶部可选择矿区和空间，包括无效草稿。
5. 拖动控制点、手柄或空间后松开鼠标，等待自动构建；也可点击 **检查并构建**。
6. 点击 **保存地图**，同时保存控制数据和构建结果。修改后未保存的地图仍会有星号。

示例包含：两个主房间、双侧曲线主通道、重叠大厅、隐藏空洞、凹形空洞、支线房间及其通道、一个可挖堵块。初始为 36 个岩石分块；不是把整条矿道合并到单个 30,000 面网格。

`Scripts/show_manual_mine.py` 可加载示例并打开编辑器。它会切换地图，运行前先保存自己的工作。

## 通道：两侧钢笔与整体弯曲

- **边界 A、边界 B 都从起点向终点绘制**，不需要相同点数。系统反向拼接 B 来闭合截面。
- 点击节点选择；左键拖节点移动；选中曲线节点后拖其切线手柄。
- **角点**用于折线；**平滑点**两手柄镜像联动；**独立手柄**可分开控制进出方向。
- **Ctrl + 点击曲线**插入节点，按贝塞尔细分保留原曲线，而不是重新拟合。
- **选择 / 钢笔追加**切换模式：点击加点，按住拖动可给新点拉出手柄；通道用 **切换 A / B**分别画两侧。
- **Shift** 多选节点；**锁定 / 解锁点**保护节点；Delete 删除选中点。绑定房间的端点不能直接删改位置。
- **整体弯曲**出现三个绿色导向柄，两侧一起变形；保留锁定点、首尾端点和已有手柄偏移。它不是重新生成等宽通道。
- 整体弯曲的节点对应关系按路径顺序持久保存，折返处不会按最近距离突然跳段。大幅增删节点后可点 **重绑弯曲导向**。
- 右键拖动平移、滚轮缩放、F 适应视图；可切换 10 cm 吸附。拖动期间 Esc 取消本次拖动；Ctrl+Z / Ctrl+Y 或顶部按钮撤销/重做。
- **反转当前边界**只适用于未绑定房间的边界，便于修复手绘方向。

## 房间和入口

- 主房间仍使用 `MiningLayoutRoom`；支线房间使用 `MiningManualShape` 的“支线房间”类型。
- 拖房间内部移动；黄色方柄调整宽、高。房间增高时底面不移动。前后深度在右侧填写。
- 通道选中后点击 **绑定起点房间 / 绑定终点房间**，再点目标房间的一面墙。支持左右墙及顶部/底部；Esc 取消绑定。
- 入口可调墙面、沿墙偏移、开口大小和深度偏移。移动/缩放房间后，端点跟随入口，中段控制点不被覆盖。
- 入口不能大于所在墙面或超出房间深度；这时会报告错误，不会偷偷缩小入口。
- 主通道必须连接矿区指定的两个主房间；支线允许接同矿区的支线房间。与已有通道直接相交也能连通，不要求每个端点都绑定房间。
- 同一矿区进入同一主房间的额外通道必须走主入口所在墙面，避免完成后的封口与回收不一致。
- **初始化主线连接**只在没有主通道时创建；已有主线只会选中它，不会覆盖手绘数据。右侧“初始化两房间连接（替换两侧）”是显式重置操作，可以撤销。

## 自己添加空洞、支线、堵块

| 操作 | 用途 |
| --- | --- |
| + 矩形空洞 / + 椭圆空洞 | 生成可编辑的闭合轮廓，之后可拖点、拉曲线、调黄柄大小 |
| + 手绘空洞 | 从空白草稿逐点绘制；至少三个节点，支持凹形，不以凸包代替 |
| + 支线房间 | 添加独立房间，可拖位置和尺寸，再画支线连接 |
| + 支线通道 | 添加可立即调整的双侧短通道；绑定端点或直接与其它空洞相交 |
| + 空白通道 | 从零画 A/B 两侧 |
| + 可挖堵块 | 在已清空的空间中填回普通可挖岩石；可逐点修改轮廓 |
| 复制空间 | 独立复制控制数据；通道副本清除房间绑定，避免意外多开门 |

空洞默认就是空的，与通道重叠时合并为空间，不生成夹在中间的基岩墙。隐藏空洞需要与通道**实际留出岩石距离**；“隐藏空洞标记”只是开发小地图的分类，不会自动封口或强制隐藏。可挖堵块当前使用普通岩石材质，不是旧系统的紫色引导岩材质遮罩。

闭合空洞的黄色尺寸柄缩放已有节点及其手柄；锁定节点保持原位。右侧“宽高（房间/初始形状）”对空洞只用于初始化矩形/椭圆，不会随意重置已画轮廓。

## 岩石范围、基岩和安全构建

- 手绘矿区有显式的 `RockSize`，矿区 Actor 位置是范围中心。轮廓必须处于范围内，不会自动扩大矿区。
- 普通岩石填在空洞之外；不可破坏基岩在矿区外边界以及主房间外墙，不为每个空洞单独套一层基岩。
- 自交、重叠边、退化轮廓、入口过大、轮廓越界、布尔运算失败或分块超限会拒绝构建。红色表示有问题的轮廓；底部/右侧显示原因。
- **失败后保留上次成功的地形**，同时保留失败的编辑草稿供修复/撤销。所以错误状态下画布和可玩的三维地形可能暂时不同。
- 拖动时先预览轮廓，释放后再重建。手绘地图即使三维视口没在刷新，也有独立编辑器调度处理自动重建。
- 保持原有预算：每块最多 **30,000 三角形**、每矿区最多 **128 块**。不通过提高上限换取编辑自由；复杂曲线仍会增加生成成本和初始三角面。
- 默认采样误差 8 cm，可调 2–50 cm；每侧最多 128 个源控制点、512 个采样点。先用少量点做大轮廓，再增加局部细节。
- Play 时锁定钢笔编辑，运行时使用保存的生成网格。进入支线房间不会推进主线；到达下一主房间后沿用冻结/回收逻辑。若旧矿区越过终点墙面而无法安全回收，则保守保留冻结地形，不冒险删除。
- 开发小地图默认显示可旋转三维模型，按住 Alt 移动鼠标旋转，V 仍可切回 X/Z 等平面视图。凹形轮廓和空洞位置来自真实设计截面；不是玩家挖掘表面的实时扫描。

## 在自己的地图中使用

建议先复制示例地图编辑。新增矿区的流程：

1. 保留或放置两个 `MiningLayoutRoom`，设置位置和尺寸。
2. 钢笔编辑器点 **新建矿区**，右侧指定 `FromRoom`、`ToRoom`，设置岩石中心与 `RockSize`。
3. 点 **初始化主线连接**，然后自由编辑两侧、添加空洞与支线。
4. 将矿区加入对应 `MiningTunnelGenerator.HollowRegions`；启用 `Hollow Region Prototype`、`Direct Room Faces`、`Automatic Chunks`，房间顺序与区域连接顺序对应。
5. 检查并构建，确认三维碰撞和小地图，保存地图。

新建按钮不会替换旧地图、不会自动改生成器的矿区列表；旧自动生成/旧空腔地图仍可使用。本版不提供旧样条/空间控制器到钢笔节点的无损自动转换。

## 版本边界和验证

这是 **X/Z 截面 + Y 方向厚度**的手工设计器，不是任意三维隧道建模器。Actor 保持零旋转、单位缩放；用节点、宽高和深度编辑。暂不支持每个节点独立变化 Y 厚度、三维扭转或自动绕行。

源码：`Source/BrainMining/MiningManual*` 与 `Source/BrainMiningEditor/Private/SMiningManualEditor.*`、`SMiningPenCanvas.*`。

- 原生：`BrainMining.Manual.*`，验证凹多边形、网格绕序/布尔运算、精确插点、稳定整体弯曲和锁定点。
- `Scripts/verify_manual_mine.py`：几何、碰撞、入口、空洞、堵块、小地图、失败回退及挖掘重置。
- `Scripts/verify_manual_editor.py`：真实编辑器自动重建、事务撤销/重做及失败恢复；`-ManualAutoQuit` 完成后退出。
- `Scripts/run_manual_runtime.py`：PIE 真实 CharacterMovement、上升和挖掘，主线/支线、冻结与重置；`-ManualAutoQuit` 完成后退出。
- `Scripts/verify_manual_compatibility.py`：逐张加载重建非手绘旧地图，不保存修改；验证闭合网格与原预算。
- 结果在 `Saved/Validation/manual_*.json`。这些脚本会切换地图，运行前保存自己的工作。

本次新增的是工程源码、工具和示例地图。未重新 Cook 或发布打包成品；`Builds/` 内旧游戏包不会自动获得新地图和功能。

本机交付验证：Editor Development 与 Game Shipping 编译通过；19 项 `BrainMining.*` 原生测试通过；手绘几何 41 项、打开钢笔画布的编辑器事务/自动重建 12 项、真实 PIE 行走/挖掘 10 项检查通过。9 张旧地图加载检查通过，存在生成器的地图均成功重建；旧地图文件相对保留用户修改后的备份没有变化。另实测鼠标拖节点、切线手柄、空洞尺寸柄及 Ctrl+Z。这里验证的是功能和原预算，不代表已做复杂关卡的帧率压测。
