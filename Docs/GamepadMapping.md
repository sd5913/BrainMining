# 手柄输入与验收

适用于主流程及独立思维、镜像、回声、卡牌和结尾场景。Xbox 命名；PlayStation 按物理位置对应底部确认、右侧返回、左侧交互、顶部工具。

## 默认布局

| 输入 | 探索 | 场景覆盖 |
|---|---|---|
| 左摇杆 | 移动 | 卡牌、菜单、图鉴、升级的方向导航 |
| 右摇杆 | 视角 | 电脑/编辑/菜单光标；图鉴旋转 |
| A | 跳跃，按住喷气 | 卡牌阶段确认；电脑点击；编辑交换；菜单确认 |
| LT | 辅助跳跃/喷气，可配置关闭 | 电脑光标精调；图鉴缩小 |
| RT | 挖矿、钻机、装备炸弹后的投掷、回声敲击 | 电脑和界面点击；编辑拖拽；图鉴放大 |
| B | 创造飞行下降 | 返回最上层界面；电脑退出；卡牌离座确认 |
| X | 目标交互 | 卡牌选中/取消、胜利领奖 |
| Y | 钻机切换 | 普通/镜像思维编辑；卡牌末轮全选/清空；图鉴复位 |
| LB | 预留 | 普通思维关闭左侧，镜像清空；图鉴前一项 |
| RB | 装备/收起炸弹 | 普通思维关闭右侧，镜像交换；图鉴后一项 |
| View | 地图 | B 返回 |
| Menu | 暂停 | 在卡牌、电脑、思维编辑、图鉴和升级上打开暂停；关闭后恢复原界面 |
| 十字键上 | 图鉴 | 界面方向导航 |
| 十字键右 | 升级面板 | A 确认购买，B 关闭；不会按住连购 |
| 十字键下 | 长按 0.8 秒请求当前场景重置 | 保留卡牌房间、结尾及矿场自身的重置限制 |

## 输入边界

- 设备事件由本地玩家子系统先行处理，避免默认 IMC 再次处理同一手柄动作。
- 场景内直接调用语义动作，不通过模拟 G/R/Tab 绕过当前场景规则。
- RT 投弹后不会接着挖矿。开场、未解锁装备、遭遇禁用、暂停和界面输入都需要遵守各自限制。
- 切换上下文、Pawn、区域、失焦或断连时释放挖矿、飞行、拖拽及确认键。
- 卡牌 B 先显示离座后果，A 才执行离座重开；再次 B 取消。
- 电脑点击使用当前光标命中的 Widget Interaction，不调用移动端的自动回复。
- 升级界面显示当前等级、下一效果和材料/金币需求；只有明确确认才购买。
- 键鼠输入切回原提示；手柄模式增加当前上下文提示与 X 交互提示。

## 配置

在 DefaultGame.ini 的 [/Script/BrainMining.MiningGamepadSubsystem] 节中可配置：

- StickDeadZone：默认 0.18，径向死区。
- LookDegreesPerSecond：默认 135。
- CursorPixelsPerSecond：默认 900，电脑 LT 精调至四分之一速度。
- bInvertLookY：默认 false。
- bLeftTriggerFlight：默认 true。
- ResetHoldSeconds：默认 0.8，最小有效时长 0.4 秒。
