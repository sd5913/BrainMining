## 修复

- 卡牌房采用新版特效时，不再每帧先执行整套旧版特效。避免同一批粒子展示组件先更新、切换材质再隐藏的重复工作；保留原有新版特效数量、时序、音效和钻头奖励。
- 存档读取依次尝试正式槽、完整临时槽、备份槽。标题菜单会识别可恢复的存档；损坏的正式槽不会覆盖有效备份。读入候选存档前验证版本、区域、地形对象和分块引用。
- 增加成品包检查接口与 Python 回归脚本。接口必须同时指定 `-MiningQA` 和独立 `-UserDir` 才启用；正常启动不轮询文件、不提供测试控制。接口只使用本地目录，没有网络监听。
